# 매일 글 3개 자동 작성 규칙

매일 아침 예약 작업이 이 문서를 읽고 글 3개를 써서 이 브랜치에 올립니다.
같은 날 오전 9시 5분(한국 시간)에 `Deploy to GitHub Pages` 워크플로가 자동으로 배포합니다.

## 주제 고르기

- 구글에서 꾸준히 검색이 많은 IT 생활 정보만 고릅니다. (예: "갤럭시 캡처 방법", "프린터 오프라인 해결")
- 카테고리는 `src/navigation.ts` 의 IT 카테고리 중 하나: 스마트폰, 윈도우·PC, 오류 해결, 웹·블로그. 하루 3개는 서로 다른 카테고리로 섞습니다.
- `무협 게임` 카테고리는 자동 작성하지 않습니다.
- `src/data/post/` 에 이미 있는 글과 주제가 겹치면 안 됩니다.
- 금방 바뀌는 정보(가격, 지원금, 이벤트, 출시 루머)는 피합니다.

## 정보 검증 (필수)

- 모든 절차와 메뉴 이름은 공식 고객지원 문서(삼성, 애플, 마이크로소프트, 구글, 카카오 등)에서 직접 확인합니다.
- 공식 문서로 확인되지 않는 내용은 쓰지 않습니다.
- 글 끝에 `_참고: 출처 문서 이름_` 을 적습니다.

## 글 형식

- 파일: `src/data/post/<영문-슬러그>.md`
- frontmatter: `publishDate` (그날 09:00, 10:00, 11:00 +09:00), `title`, `excerpt`, `category`, `coverIcon`, `tags`
- `coverIcon`: 글 주제에 맞는 Tabler 아이콘 (예: `tabler:printer-off`, `tabler:bluetooth-off`). 다른 글과 겹치지 않게 고릅니다. 이름은 `node_modules/@iconify-json/tabler/icons.json` 에 있어야 합니다.
- 이미지 넣지 않기 (`coverIcon` 아이콘으로 표지가 자동으로 나옵니다). 사진이 들어갈 곳에는 `<!-- 스크린샷 자리: ... -->` 주석.
- 쉬운 한국어, 번호 매긴 단계, 소제목, 마지막에 정리. "메뉴 이름은 버전에 따라 다를 수 있다" 안내.
- 다른 글 링크는 반드시 슬래시(/)로 시작: `[제목](/pc-no-sound)` (슬래시 없이 쓰면 실제 사이트에서 404가 납니다)

## 올리기 전 확인

1. `npx prettier -w src/data/post`
2. `npm run check`
3. `npx astro build` 성공
4. 커밋 후 `git pull --rebase` 하고 푸시
