무협 게임의 재미는 결국 **강호라는 세계**에서 나온다고 생각합니다. 그래서 문파 이름은 모두 새로 짓되, 정파·사파·마교·무림맹 같은 익숙한 장르 용어는 그대로 살렸습니다.

## 강호의 역사

| 시점         | 사건                                                                                        |
| ------------ | ------------------------------------------------------------------------------------------- |
| 아주 먼 옛날 | 전설의 무인 **무극자**가 정·사·마가 나뉘기 전의 무공을 남김                                 |
| 300년 전     | **천마혈겁.** 초대 천마가 중원을 피로 물들이고, 정파가 무림맹을 세워 천마를 서역으로 몰아냄 |
| 100년 전     | **정사대전.** 정파와 사파가 10년 동안 싸운 끝에 휴전, 사파 문파들이 사도련을 만듦           |
| 13년 전      | **혈월의 밤.** 강호를 뒤흔든 사건이 일어나고, 그 진실은 아직 아무도 모름                    |

게임은 이렇게 아슬아슬하게 유지되던 **세 세력의 균형이 무너지기 직전**에 시작합니다.

## 세 세력과 대표 문파

### 정파 (무림맹)

- **청운검문:** 도가 계열의 검법 명문. 엄격하고 자존심이 강합니다.
- **금강사:** 권법과 외공의 불가 사찰. 어려운 사람을 잘 돕습니다.
- **백의방:** 거지들의 연합이자 강호 제일의 정보망입니다.

### 사파 (사도련)

- **흑룡방:** 장강 물길을 쥐고 통행세를 걷는 수적 출신 세력입니다.
- **만독문:** 독과 약을 함께 다루는 문파입니다.
- **녹림채:** 산적들의 연합. 첫 데모에서 만나는 적이 바로 이들입니다.

### 마교 (천마신교)

- **혈마전:** 전면전으로 중원을 되찾자는 강경파입니다.
- **성화단:** 천마를 신으로 모시는 온건파입니다.

같은 세력 안에서도 사이가 좋지만은 않습니다. 맹주 자리, 교주 자리를 둘러싼 다툼이 이야기의 중요한 갈등이 됩니다.

## 주인공이 여행할 지역

| 지역       | 풍경                                     |
| ---------- | ---------------------------------------- |
| **청석진** | 강변의 작은 마을, 복래객잔이 있는 고향   |
| **녹림산** | 울창한 숲과 폭포, 산적들의 산채          |
| **강주성** | 장강 나루의 큰 도시, 세 세력이 뒤섞인 곳 |
| **청운산** | 구름 위의 봉우리와 절벽                  |
| **만독림** | 독충과 안개가 가득한 남쪽 습지           |
| **혈사곡** | 붉은 모래의 서역 협곡                    |
| **중도**   | 무림맹 총단이 있는 천하의 수도           |

처음에는 청석진과 녹림산에서 시작하고, 업데이트마다 지역을 하나씩 넓혀 갈 계획입니다. 특히 강주성에서는 플레이어가 **어느 세력의 길을 걸을지** 고르게 됩니다.
