지금 보고 계신 이 블로그는 **서버 비용 없이** 운영되고 있습니다. 어떻게 만들었는지 전체 흐름을 정리해 봤습니다.

## 어떻게 무료로 운영할 수 있을까?

블로그 글은 한 번 쓰면 자주 바뀌지 않습니다. 그래서 방문할 때마다 서버가 페이지를 만들 필요 없이, **미리 만들어 둔 HTML 파일을 그대로 보여 주면** 됩니다. 이런 사이트를 **정적 사이트**라고 하고, 정적 사이트는 무료로 올려 둘 수 있는 곳이 많습니다.

## 사용한 도구

| 역할      | 사용한 것                    | 비용 |
| --------- | ---------------------------- | ---- |
| 사이트 틀 | Astro + AstroWind 템플릿     | 무료 |
| 코드 보관 | GitHub 저장소                | 무료 |
| 호스팅    | GitHub Pages                 | 무료 |
| 도메인    | (선택) 개인 도메인 연결 가능 | 유료 |

## 만드는 순서

### 1. GitHub 저장소 만들기

GitHub에 가입하고 새 저장소(Repository)를 만듭니다. 이곳에 홈페이지 파일이 모두 보관됩니다.

### 2. 템플릿 가져오기

처음부터 디자인할 필요 없이 무료 템플릿을 사용했습니다. **AstroWind**는 블로그, 카테고리, 다크 모드, 모바일 화면까지 기본으로 갖춘 MIT 라이선스 템플릿입니다.

### 3. 글 쓰기

글은 **마크다운(.md) 파일**로 씁니다. 제목, 날짜, 카테고리만 맨 위에 적고 그 아래에 본문을 쓰면 됩니다.

```md
---
title: '글 제목'
publishDate: 2026-10-15T09:00:00+09:00
category: 웹·블로그
---

여기에 본문을 씁니다.
```

### 4. GitHub Pages로 배포하기

저장소 **Settings** → **Pages** 에서 배포 방식을 **GitHub Actions**로 정하면, 배포를 실행할 때마다 사이트가 자동으로 만들어져 `아이디.github.io/저장소이름` 주소로 공개됩니다.

## 알아 둘 점

- 무료 GitHub 계정에서 GitHub Pages를 쓰려면 저장소가 **공개(Public)** 여야 합니다. 비밀번호 같은 민감한 정보는 저장소에 넣지 마세요.
- 방문자가 아주 많아지거나 광고 수익을 본격적으로 낼 계획이라면 Cloudflare Pages 같은 다른 무료 호스팅으로 옮기는 것도 방법입니다.

## 정리

**템플릿 → GitHub 저장소 → 마크다운으로 글쓰기 → GitHub Pages 배포.** 서버를 직접 관리하지 않아도 되니, 글 쓰는 데만 집중할 수 있다는 것이 가장 큰 장점입니다.
