처음엔 빨랐던 PC가 점점 느려진다면, 대부분은 **켜질 때 같이 실행되는 프로그램**과 **부족한 저장 공간** 때문입니다. 따로 최적화 프로그램을 설치하지 않아도 윈도우 기본 설정만으로 충분히 개선할 수 있습니다.

## 1. 시작 프로그램 줄이기

PC를 켤 때 자동으로 실행되는 프로그램이 많을수록 부팅이 느려집니다.

- **설정** → **앱** → **시작 프로그램**
- 평소에 바로 쓰지 않는 프로그램은 **끔**으로 바꿉니다.

또는 `Ctrl + Shift + Esc` 로 **작업 관리자**를 열고 **시작 앱** 탭에서도 끌 수 있습니다. 영향이 '높음'으로 표시된 항목부터 확인해 보세요.

## 2. 저장 공간 확보하기 (저장소 센스)

C 드라이브가 거의 꽉 차 있으면 전체 속도가 떨어집니다.

- **설정** → **시스템** → **저장소**
- **임시 파일**에서 필요 없는 파일을 정리하고, **저장소 센스**를 켜 두면 주기적으로 자동 정리됩니다.

## 3. 사용하지 않는 프로그램 삭제하기

- **설정** → **앱** → **설치된 앱**
- 오랫동안 쓰지 않은 프로그램, 처음부터 설치되어 있던 체험판 프로그램을 정리합니다.

## 4. 시각 효과 줄이기

창이 열리고 닫힐 때의 애니메이션 효과를 줄이면 오래된 PC에서 체감 속도가 좋아집니다.

1. `Win + R` 을 누르고 `sysdm.cpl` 을 입력합니다.
2. **고급** 탭 → 성능 항목의 **설정**을 누릅니다.
3. **최적 성능으로 조정**을 선택하거나, 원하는 효과만 골라서 끕니다.

## 5. 전원 모드 바꾸기 (노트북)

- **설정** → **시스템** → **전원 및 배터리** → **전원 모드**
- 충전기를 연결해 쓸 때는 **최고 성능**으로 바꾸면 더 빠르게 동작합니다. 배터리 사용 시간은 줄어들 수 있습니다.

## 6. 윈도우 업데이트 확인하기

- **설정** → **Windows 업데이트** → **업데이트 확인**

업데이트에는 성능 문제와 오류를 고친 내용이 포함되는 경우가 많습니다. 업데이트 후에는 꼭 다시 시작해 주세요.

## 그래도 느리다면

위 설정을 모두 했는데도 느리다면 하드웨어를 의심해 볼 차례입니다. 특히 **HDD(하드디스크)를 쓰는 PC라면 SSD로 교체**하는 것이 가장 효과가 큽니다. 작업 관리자의 **성능** 탭에서 디스크 종류를 확인할 수 있습니다.
