크롬은 보통 새 사이트에 로그인하면 **비밀번호를 저장할지** 물어봅니다. 그런데 어떤 사이트에서는 이 창이 안 뜨고, 저장해 둔 비밀번호가 로그인 칸에 안 채워지기도 합니다.

크롬의 비밀번호는 **Google 비밀번호 관리자**가 관리합니다. Google Chrome 고객센터의 '비밀번호 관리하기', '비밀번호 및 패스키 관련 문제 해결하기' 안내를 기준으로, 확인할 순서를 정리했습니다. PC(윈도우) 크롬과 갤럭시(안드로이드) 크롬을 함께 적었습니다.

> 크롬 버전에 따라 메뉴 이름이나 위치가 조금 다를 수 있습니다.

## 1. '비밀번호 저장 여부 확인'이 켜져 있는지 보기

Google 안내에 따르면 크롬은 기본으로 비밀번호 저장을 제안하지만, 이 옵션을 끌 수도 있습니다. 꺼져 있으면 어느 사이트에서도 저장 창이 뜨지 않으니 가장 먼저 확인합니다.

**PC 크롬**

1. 크롬 오른쪽 위 **더보기(점 3개)**를 누릅니다.
2. **비밀번호 및 자동 완성** > **Google 비밀번호 관리자**를 고릅니다.
3. 왼쪽에서 **설정**을 누릅니다.
4. **비밀번호 및 패스키 저장 여부 확인**을 켭니다.

**갤럭시(안드로이드) 크롬**

1. 크롬 앱을 열고 **더보기(점 3개)** > **설정**을 누릅니다.
2. **자동 완성 및 비밀번호** > **Google 비밀번호 관리자**를 누릅니다.
3. 오른쪽 아래 **설정**을 누릅니다.
4. **비밀번호 저장 여부 확인**을 켭니다.

## 2. 특정 사이트만 안 물어본다면 '거부된 사이트 및 앱' 확인 (PC)

다른 사이트는 잘 저장되는데 한 사이트만 안 물어본다면, 그 사이트가 **비밀번호를 저장하지 않는 사이트** 목록에 들어 있을 수 있습니다. Google 안내에 따르면 PC 크롬은 이 목록을 설정의 **거부된 사이트 및 앱**에서 관리합니다.

1. 크롬 오른쪽 위 **더보기** > **비밀번호 및 자동 완성** > **Google 비밀번호 관리자**를 고릅니다.
2. **설정**을 누릅니다.
3. **거부된 사이트 및 앱**에서 해당 사이트를 삭제합니다.

삭제한 뒤 그 사이트에 다시 로그인하면 저장 창이 뜨는지 확인해 보세요.

## 3. 저장 창이 안 떠도 직접 저장하는 방법

Google은 저장 창이 자동으로 뜨지 않아도 비밀번호를 저장할 수 있다고 안내합니다.

**주소창의 열쇠 아이콘으로 저장**

1. 비밀번호를 저장하려는 사이트에 아이디와 비밀번호를 입력합니다.
2. 주소창 오른쪽에 보이는 **비밀번호(열쇠 모양) 아이콘** > **저장**을 누릅니다.

열쇠 아이콘이 보이지 않으면, Google 안내대로 **입력한 비밀번호를 지우고 다시 로그인**해 봅니다.

**비밀번호 관리자에 직접 추가 (PC)**

1. **더보기** > **비밀번호 및 자동 완성** > **Google 비밀번호 관리자**를 고릅니다.
2. **추가**를 누릅니다.
3. 웹사이트 주소, 사용자 이름, 비밀번호를 입력하고 **저장**을 누릅니다.

갤럭시 크롬에서는 **Google 비밀번호 관리자** 화면의 검색창 아래 **비밀번호 추가**를 누르면 같은 방식으로 넣을 수 있습니다.

## 4. 저장은 됐는데 자동으로 안 채워질 때

Google은 비밀번호 칸을 눌러도 저장된 목록이 안 나오면 **크롬이 그 사이트의 입력 칸을 제대로 알아보지 못한 것**일 수 있다고 설명합니다.

- **PC**: Google 비밀번호 관리자에서 해당 사이트를 찾아 저장된 비밀번호를 확인하고 직접 입력합니다. 비밀번호를 고른 뒤 **비밀번호 표시** 아이콘을 누르면 내용을 볼 수 있습니다.
- **갤럭시**: 로그인 화면에서 **키보드 위쪽의 비밀번호 아이콘** > **비밀번호 선택**을 누르면 저장된 비밀번호를 골라 넣을 수 있습니다.

같은 사이트에 아이디를 여러 개 저장했다면 자동으로 채워지지 않고, **사용자 이름 칸을 눌러** 쓸 계정을 골라야 합니다.

## 5. 다른 브라우저에서 가져온 비밀번호가 안 보일 때

다른 브라우저나 파일에서 가져온 비밀번호는 사이트 이름이 다른 항목으로 들어가는 경우가 있다고 Google은 안내합니다. 이럴 때는 **passwords.google.com**에 들어가 검색창에 앱이나 사이트 이름을 검색해 찾습니다.

참고로 크롬에 Google 계정으로 로그인하지 않은 상태라면 비밀번호는 **이 기기에만** 저장됩니다. 다른 PC나 휴대폰에서 안 보인다면, 크롬에 같은 Google 계정으로 로그인했는지도 확인해 보세요.

## 정리

| 증상                              | 먼저 해 볼 것                                                         |
| --------------------------------- | --------------------------------------------------------------------- |
| 어느 사이트에서도 저장 창이 안 뜸 | 비밀번호 관리자 설정 > '비밀번호 저장 여부 확인' 켜기                 |
| 한 사이트만 안 물어봄 (PC)        | 설정 > '거부된 사이트 및 앱'에서 그 사이트 삭제                       |
| 저장 창이 끝내 안 뜸              | 주소창 열쇠 아이콘 > 저장, 또는 비밀번호 관리자에서 직접 추가         |
| 저장했는데 자동 입력이 안 됨      | PC는 관리자에서 확인 후 직접 입력, 갤럭시는 키보드 위 비밀번호 아이콘 |
| 가져온 비밀번호가 안 보임         | passwords.google.com에서 사이트 이름 검색                             |

크롬 관련 다른 문제는 [크롬 캐시와 쿠키 삭제 방법](/chrome-clear-cache-cookies), [크롬 다운로드 실패 해결 방법](/chrome-download-failed)도 함께 보세요.
