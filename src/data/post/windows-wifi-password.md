집이나 사무실 와이파이 비밀번호가 기억나지 않을 때, **이미 연결해서 쓰고 있는 윈도우 PC**가 있다면 거기서 바로 확인할 수 있습니다.

> **제 이야기**: 노트북에 자동으로 저장된 와이파이 비밀번호를 확인하려다 시간을 다 날린 적이 있습니다. 알고 나면 1분이면 끝나는 방법이라 정리해 둡니다.

## 방법 1: 지금 연결된 와이파이 비밀번호 보기

1. **설정** → **네트워크 및 인터넷**으로 들어갑니다.
2. 지금 연결된 와이파이의 **속성**을 누릅니다.
3. **Wi-Fi 네트워크 암호** 옆의 **표시**를 누르면 비밀번호가 나타납니다.

<!-- 스크린샷 자리: Wi-Fi 네트워크 암호 '표시' 버튼 -->

## 방법 2: 예전에 연결했던 와이파이 비밀번호 보기

지금 연결되어 있지 않아도, 예전에 연결한 적이 있는 와이파이라면 확인할 수 있습니다.

1. **설정** → **네트워크 및 인터넷** → **Wi-Fi** → **알려진 네트워크 관리**로 들어갑니다.
2. 목록에서 원하는 와이파이를 누릅니다.
3. **Wi-Fi 네트워크 암호** 옆의 **표시**를 누릅니다.

## 방법 3: 명령어로 확인하기

설정 화면에 표시 버튼이 보이지 않는다면 명령어로도 확인할 수 있습니다.

1. 시작 버튼을 누르고 `cmd` 를 검색해 **명령 프롬프트**를 엽니다.
2. 저장된 와이파이 목록을 봅니다.

```bash
netsh wlan show profiles
```

3. 비밀번호를 볼 와이파이 이름을 넣어 아래 명령을 입력합니다.

```bash
netsh wlan show profile name="와이파이이름" key=clear
```

4. 결과 중 **키 콘텐츠** 항목에 적힌 것이 비밀번호입니다.

## 알아 둘 점

- 비밀번호를 보려면 **관리자 권한**이 필요할 수 있습니다.
- 회사처럼 아이디와 비밀번호로 로그인하는 와이파이(기업용 인증)는 이 방법으로 확인되지 않습니다.
- 그래도 모르겠다면 공유기 뒷면이나 밑면 스티커에 초기 비밀번호가 적혀 있는 경우가 많습니다. (직접 바꾼 적이 없다면)
