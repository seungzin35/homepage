화상회의에 들어갔는데 "목소리가 안 들려요"라는 말을 듣거나, 게임 음성 채팅에서 내 말만 전달되지 않을 때가 있습니다. 헤드셋은 분명히 꽂혀 있는데 말이죠.

이럴 때는 고장을 의심하기 전에 **윈도우 설정**부터 확인해 보는 것이 좋습니다. Microsoft 고객지원에서 안내하는 순서대로, 쉬운 것부터 정리했습니다.

## 1. 연결과 음소거 버튼 확인

가장 먼저 기본적인 것부터 봅니다.

1. 헤드셋이나 마이크에 **음소거 버튼**이 있다면 켜져 있지 않은지 확인합니다.
2. 마이크나 헤드셋이 PC에 **제대로 꽂혀 있는지** 확인합니다.
3. 마이크가 입 가까이, 올바른 방향으로 놓여 있는지 확인합니다.
4. 블루투스 헤드셋이라면 PC와 **페어링되어 연결된 상태**인지 확인합니다. 블루투스 연결 자체가 안 된다면 [블루투스 이어폰이 PC에 연결 안 될 때 해결 방법](/bluetooth-not-connecting)을 먼저 보세요.

## 2. 앱이 마이크를 쓸 수 있게 허용하기

Microsoft는 **윈도우 11을 업데이트한 뒤 마이크가 감지되지 않는다면** 앱에 마이크 권한을 줘야 할 수 있다고 안내합니다.

1. **시작** 버튼을 누르고 **설정**을 엽니다.
2. **개인 정보 & 보안**을 누릅니다.
3. 아래로 내려 **마이크**를 누릅니다.
4. **마이크 액세스**가 켜져 있는지 확인합니다.
5. **앱에서 마이크에 액세스할 수 있도록 허용**이 켜져 있는지 확인하고, 목록에서 마이크를 쓸 앱을 켭니다.
6. 줌, 디스코드처럼 따로 설치한 프로그램(데스크톱 앱)은 이 목록에 나오지 않습니다. 대신 **데스크톱 앱이 마이크에 액세스할 수 있도록 허용**이 켜져 있어야 합니다.

<!-- 스크린샷 자리: 설정 > 개인 정보 & 보안 > 마이크 (마이크 액세스, 데스크톱 앱 허용 스위치가 보이게) -->

웹캠에 달린 마이크를 쓰는 경우에는 카메라 권한도 필요할 수 있습니다. 같은 **개인 정보 & 보안** 화면에서 **카메라**를 눌러 켜져 있는지 확인하세요.

## 3. 쓰려는 마이크가 입력 장치로 골라져 있는지 확인

마이크가 여러 개(노트북 내장 마이크, 헤드셋, 웹캠)면 윈도우가 엉뚱한 마이크를 쓰고 있을 수 있습니다.

1. **시작 → 설정 → 시스템 → 사운드**로 갑니다.
2. **입력** 부분의 **말하기 또는 녹음을 위한 장치 선택**에서 쓰려는 마이크를 고릅니다.

<!-- 스크린샷 자리: 설정 > 시스템 > 사운드 > 입력 (말하기 또는 녹음을 위한 장치 선택 목록이 보이게) -->

## 4. 마이크 테스트하고 입력 볼륨 올리기

목소리가 너무 작게 들린다는 말을 듣는다면 입력 볼륨을 확인합니다.

1. **설정 → 시스템 → 사운드**에서 **입력** 아래의 마이크를 눌러 속성 화면을 엽니다.
2. **테스트 시작**을 누르고 평소처럼 말합니다.
3. **테스트 중지**를 누른 뒤 녹음된 샘플을 **재생**해서 들어 봅니다.
4. 소리가 작다면 **입력 볼륨** 슬라이더를 올립니다.

## 5. 문제 해결사 실행하기

윈도우에 들어 있는 문제 해결사로 자동 점검을 해 볼 수도 있습니다.

1. **설정 → 시스템 → 사운드**로 갑니다.
2. 아래로 내려 **고급** 부분의 **일반적인 소리 문제 해결**에서 **입력 장치**를 고릅니다.
3. 화면 안내를 따라갑니다.

## 6. 마이크를 아예 인식하지 못할 때: 오디오 드라이버 다시 설치

위 방법으로도 안 되고, 윈도우가 마이크 자체를 찾지 못한다면 오디오 드라이버를 다시 설치해 봅니다.

1. **시작** 버튼을 마우스 오른쪽 단추로 누르고 **장치 관리자**를 엽니다.
2. **소리, 비디오 및 게임 컨트롤러**를 펼칩니다.
3. 오디오 장치를 마우스 오른쪽 단추로 누르고 **장치 제거**를 고릅니다.
4. **이 장치의 드라이버 제거 시도** 상자에 체크하고 **제거**를 누릅니다.
5. PC를 **다시 시작**합니다. 윈도우가 오디오 장치와 드라이버를 자동으로 다시 설치하려고 합니다.
6. 다시 설치되지 않았다면 장치 관리자에서 **소리, 비디오 및 게임 컨트롤러**를 마우스 오른쪽 단추로 누르고 **하드웨어 변경 내용 검색**을 누릅니다.
7. 그래도 안 되면 오디오 드라이버를 마우스 오른쪽 단추로 누르고 **드라이버 업데이트**를 고릅니다.

> 메뉴 이름은 윈도우 버전이나 업데이트에 따라 조금 다를 수 있습니다.

## 정리

- 먼저 **음소거 버튼과 연결 상태**를 봅니다.
- **설정 → 개인 정보 & 보안 → 마이크**에서 마이크 액세스와 데스크톱 앱 허용을 켭니다.
- **설정 → 시스템 → 사운드 → 입력**에서 쓰려는 마이크를 고르고, 테스트로 입력 볼륨을 맞춥니다.
- 그래도 안 되면 **문제 해결사**, 마지막으로 **장치 관리자에서 오디오 드라이버 재설치**를 해 봅니다.

반대로 스피커에서 소리가 안 나온다면 [컴퓨터에서 갑자기 소리가 안 날 때 확인할 5가지](/pc-no-sound)를 확인해 보세요.
