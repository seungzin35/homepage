메신저나 은행 앱 알림이 **아예 안 오거나**, 앱을 열어야 그제야 **밀린 알림이 한꺼번에 들어오는** 경우가 있습니다.

삼성 공식 안내에 따르면 갤럭시에서 앱 알림을 막는 원인은 크게 세 가지입니다. **방해 금지·절전 모드**, 배터리를 아끼려고 앱을 재우는 **절전 상태 앱**, 그리고 **앱별 알림 설정**입니다. 아래 순서대로 하나씩 확인해 보세요.

> 메뉴 이름과 들어가는 경로는 기기 모델과 소프트웨어(One UI) 버전에 따라 조금씩 다를 수 있습니다.

## 방법 1: 방해 금지와 절전 모드 끄기

가장 먼저 볼 곳은 빠른 설정창입니다. 삼성 안내에서는 두 기능이 켜져 있으면 알림이 막히거나 보이지 않을 수 있다고 설명합니다.

1. 화면 맨 위에서 아래로 쓸어내려 **빠른 설정창**을 엽니다.
2. **방해 금지** 아이콘이 켜져(색이 들어와) 있으면 눌러서 끕니다.
3. **절전 모드** 아이콘이 켜져 있으면 눌러서 끕니다.
4. 알림이 오지 않던 앱으로 테스트 알림이 오는지 확인합니다. (예: 다른 사람에게 메시지를 한 통 보내 달라고 하기)

<!-- 스크린샷 자리: 빠른 설정창 전체 화면 (방해 금지·절전 모드 아이콘이 꺼진 모습이 보이게) -->

삼성 배터리 안내에 따르면 **절전 모드를 켜면 백그라운드 실행 제한이 모든 앱에 적용**됩니다. 배터리가 부족할 때 절전 모드를 켜 두고 잊어버리면, 그동안 알림이 늦게 오는 이유가 될 수 있습니다.

## 방법 2: 절전 상태 앱에서 빼기 (가장 흔한 원인)

갤럭시는 배터리를 아끼려고 잘 쓰지 않는 앱을 **절전 상태**나 **초절전 상태**로 바꿉니다. 삼성 안내에 나온 두 상태의 차이는 다음과 같습니다.

| 상태           | 삼성 안내 내용                                                                        |
| -------------- | ------------------------------------------------------------------------------------- |
| 절전 상태 앱   | 간헐적으로만 백그라운드에서 실행되고, 앱 업데이트와 **알림이 지연**될 수 있음         |
| 초절전 상태 앱 | 어떤 경우에도 백그라운드에서 실행되지 않고, **앱을 직접 열어야** 업데이트·알림을 받음 |

"앱을 열어야 알림이 한꺼번에 온다"는 증상이라면 이 목록에 들어가 있을 가능성이 큽니다. 내가 넣지 않았어도, 오래 쓰지 않은 앱은 **자동으로** 이 목록에 들어갈 수 있습니다.

1. **설정** 앱을 엽니다.
2. **배터리**를 누릅니다. (기기에 따라 **디바이스 케어** → **배터리**)
3. **백그라운드 앱 사용 제한**을 누릅니다.
4. **절전 상태 앱**과 **초절전 상태 앱**을 차례로 열어 봅니다.
5. 알림이 안 오는 앱이 보이면 그 앱을 길게 누른 뒤 **삭제**(목록에서 빼기)를 누릅니다.

### 다시 잠들지 않게 '자동 절전 예외 앱'에 넣기

목록에서 빼도 시간이 지나면 다시 자동으로 들어갈 수 있습니다. 카카오톡, 은행·인증 앱처럼 알림이 중요한 앱은 예외로 등록해 두세요.

1. **설정** → **배터리** → **백그라운드 앱 사용 제한**으로 들어갑니다.
2. **자동 절전 예외 앱**을 누릅니다.
3. 오른쪽 위 **+** 를 누릅니다.
4. 예외로 둘 앱을 고른 뒤 **추가**를 누릅니다.

<!-- 스크린샷 자리: 자동 절전 예외 앱 목록에 앱을 추가한 화면 (+ 버튼과 추가된 앱이 보이게) -->

## 방법 3: 앱별 알림이 켜져 있는지 확인하기

특정 앱 하나만 알림이 안 온다면, 그 앱의 알림 자체가 꺼져 있을 수 있습니다.

1. **설정** 앱을 엽니다.
2. **애플리케이션**을 누릅니다.
3. 알림이 안 오는 앱을 찾아 누릅니다. (오른쪽 위 돋보기로 검색할 수 있습니다.)
4. **알림**을 누릅니다.
5. **알림 허용** 스위치를 켭니다. 소리와 진동으로도 알리게 하려면 소리·진동 관련 항목도 켭니다.

삼성 안내에 따르면 앱에 따라 **알림 종류(카테고리)를 따로 고를 수 있습니다.** 예를 들어 메신저 앱은 "메시지 알림"과 "기타 알림"이 나뉘어 있을 수 있으니, 받고 싶은 종류가 꺼져 있지 않은지도 살펴보세요.

## 방법 4: 앱 안의 알림 설정도 확인하기

휴대폰 설정에서 다 켜 두었는데도 안 온다면, **앱 자체의 설정 메뉴**에 알림 스위치가 따로 있을 수 있습니다. 삼성 안내에서도 일부 앱은 앱 안에 별도의 알림 설정이 있으니 앱을 열어 설정·메뉴·도움말을 확인하라고 설명합니다.

- 앱 안의 **설정** → **알림** 메뉴에서 알림이 켜져 있는지 봅니다.
- 앱이 오래된 버전이면 **Play 스토어**나 **Galaxy Store**에서 최신 버전으로 업데이트합니다. 삼성 배터리 안내에서도 문제가 생긴 앱은 최신 버전으로 업데이트하라고 권합니다.

## 그래도 안 되면

위 방법을 모두 해도 알림이 오지 않는다면 **Samsung Members** 앱의 **오류 신고** 기능으로 증상을 삼성에 보낼 수 있습니다. 알림이 안 온 직후에 보내면 원인을 찾는 데 도움이 됩니다. 여러 앱에서 동시에 같은 문제가 계속된다면 삼성전자서비스센터 점검도 고려해 보세요.

## 정리

| 증상                               | 먼저 확인할 곳                                                      |
| ---------------------------------- | ------------------------------------------------------------------- |
| 모든 앱 알림이 조용하다            | 빠른 설정창 → **방해 금지** 끄기                                    |
| 배터리 아끼려고 절전 모드를 켰었다 | 빠른 설정창 → **절전 모드** 끄기                                    |
| 앱을 열어야 알림이 한꺼번에 온다   | 배터리 → 백그라운드 앱 사용 제한 → **절전·초절전 상태 앱**에서 빼기 |
| 중요한 앱이 자꾸 다시 잠든다       | 백그라운드 앱 사용 제한 → **자동 절전 예외 앱**에 추가              |
| 특정 앱 하나만 알림이 없다         | 설정 → 애플리케이션 → 앱 → 알림 → **알림 허용**                     |
| 휴대폰 설정은 다 켜져 있다         | 앱 안의 알림 설정, 앱 최신 버전 업데이트                            |

대부분은 **방법 2**의 절전 상태 앱에서 해결됩니다. 배터리가 빨리 닳아서 절전 기능을 많이 켜 두었다면 [갤럭시 배터리가 빨리 닳을 때](/galaxy-battery-drain)도 함께 참고해 보세요.
