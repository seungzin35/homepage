인터넷 은행, 관공서, 학교 사이트에서 버튼을 눌렀는데 아무 창도 안 뜰 때가 있습니다. 대부분은 크롬이 **팝업 창을 자동으로 막았기 때문**입니다. 크롬은 기본적으로 팝업을 차단하고, 막았을 때는 주소창에 **팝업 차단됨** 표시가 나타납니다.

팝업을 모두 열어 두면 광고 창이 마구 뜰 수 있으니, **필요한 사이트만 골라서 허용**하는 방법을 먼저 알아 두는 게 좋습니다.

> 이 글은 구글 Chrome 고객센터 공식 문서를 바탕으로 정리했습니다. 메뉴 이름은 크롬 버전에 따라 조금 다를 수 있습니다.

## 1. 컴퓨터: 지금 보는 사이트만 팝업 허용하기

가장 많이 쓰는 방법입니다. 팝업이 막힌 그 사이트에서 바로 허용합니다.

1. 컴퓨터에서 **Chrome**을 엽니다.
2. 팝업이 차단된 페이지로 갑니다.
3. 주소창 오른쪽의 **팝업 차단됨** 아이콘을 클릭합니다.
4. 지금 열고 싶은 팝업이 있다면 목록에 나온 링크를 클릭합니다.
5. 앞으로도 이 사이트의 팝업을 계속 열려면 **[사이트]에서 팝업 및 리디렉션을 항상 허용**을 고른 뒤 **완료**를 누릅니다.

<!-- 스크린샷 자리: 주소창의 팝업 차단됨 아이콘을 누른 화면 -->

허용한 뒤에도 창이 안 뜨면 페이지를 새로고침(F5)한 다음 버튼을 다시 눌러 보세요.

## 2. 컴퓨터: 팝업 기본 설정 바꾸기

모든 사이트에 적용되는 기본값을 바꾸는 방법입니다.

1. 컴퓨터에서 **Chrome**을 엽니다.
2. 오른쪽 위 **더보기**(점 3개) → **설정**을 클릭합니다.
3. **개인 정보 및 보안** → **사이트 설정** → **팝업 및 리디렉션**을 클릭합니다.
4. 원하는 옵션을 기본 설정으로 선택합니다.

<!-- 스크린샷 자리: 설정 > 개인 정보 및 보안 > 사이트 설정 > 팝업 및 리디렉션 화면 -->

기본값은 차단으로 두고, 필요한 사이트만 1번 방법으로 허용하는 쪽을 추천합니다.

## 3. 컴퓨터: 허용했던 사이트를 다시 차단하기

예전에 허용해 둔 사이트에서 광고 창이 자꾸 뜬다면 다시 막을 수 있습니다.

1. 오른쪽 위 **더보기** → **설정** → **개인 정보 및 보안** → **사이트 설정**을 클릭합니다.
2. **팝업 및 리디렉션**을 클릭합니다.
3. **팝업 전송 및 리디렉션 사용이 허용됨** 목록에서 그 사이트를 찾습니다.
4. 사이트 오른쪽의 **더보기** → **차단**을 클릭합니다.

목록에 없는 사이트를 미리 막고 싶다면 **팝업 전송 또는 리디렉션 사용이 허용되지 않음** 옆의 **추가**를 누르고 주소를 입력한 뒤 **추가**를 누르면 됩니다.

## 4. 안드로이드 휴대폰: 팝업 허용·차단하기

### 특정 사이트만 허용하기

1. 휴대폰에서 **Chrome**을 엽니다.
2. 팝업이 차단된 페이지로 갑니다.
3. 화면 아래에 나오는 **항상 표시**를 탭합니다.

### 모든 사이트 설정 바꾸기

1. **Chrome**을 엽니다.
2. 주소창 오른쪽의 **더보기**(점 3개) → **설정**을 탭합니다.
3. **사이트 설정** → **팝업 및 리디렉션**을 탭합니다.
4. **팝업 및 리디렉션** 스위치를 켜거나 끕니다.

<!-- 스크린샷 자리: 안드로이드 크롬 설정 > 사이트 설정 > 팝업 및 리디렉션 화면 -->

## 5. 팝업을 막았는데도 계속 뜬다면

구글 안내에 따르면 두 가지를 확인해 보라고 합니다.

- **사이트 알림을 구독했을 수 있습니다.** 예전에 어떤 사이트에서 "알림을 받으시겠습니까?"에 **허용**을 눌렀다면, 팝업이 아니라 알림으로 광고가 뜹니다. 이때는 그 사이트의 알림을 차단해야 합니다.
- **컴퓨터나 휴대폰이 악성 프로그램(멀웨어)에 감염되었을 수 있습니다.** 이상한 광고가 계속된다면 악성 프로그램 검사를 해 보세요.

또 회사나 학교에서 관리하는 컴퓨터라면 이 설정을 직접 바꿀 수 없고, 관리자가 정해 둔 팝업 설정을 따릅니다.

## 정리

| 하고 싶은 것                    | 방법                                                      |
| ------------------------------- | --------------------------------------------------------- |
| 지금 사이트만 팝업 열기 (PC)    | 주소창 **팝업 차단됨** 아이콘 → **항상 허용** → 완료      |
| 전체 기본값 바꾸기 (PC)         | 설정 → 개인 정보 및 보안 → 사이트 설정 → 팝업 및 리디렉션 |
| 특정 사이트만 허용 (안드로이드) | 화면 아래 **항상 표시**                                   |
| 막았는데도 광고가 뜸            | 사이트 알림 차단, 악성 프로그램 검사                      |

모든 팝업이 광고는 아닙니다. 은행이나 관공서처럼 꼭 필요한 사이트는 허용해 두고, 나머지는 차단 상태로 두는 것이 가장 안전합니다.

크롬이 느려지거나 사이트가 이상하게 보일 때는 [크롬 캐시·쿠키 삭제 방법](/chrome-clear-cache-cookies)도 함께 참고해 보세요.
