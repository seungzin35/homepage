> 예시 글입니다. 내용을 자유롭게 바꾸거나 지워 주세요.

| 단축키 (Windows / Mac)       | 기능                   |
| ---------------------------- | ---------------------- |
| Ctrl + T / ⌘ + T             | 새 탭 열기             |
| Ctrl + Shift + T / ⌘ + ⇧ + T | 방금 닫은 탭 다시 열기 |
| Ctrl + L / ⌘ + L             | 주소창으로 이동        |
| Ctrl + W / ⌘ + W             | 현재 탭 닫기           |
| Ctrl + Tab                   | 다음 탭으로 이동       |
| Ctrl + F / ⌘ + F             | 페이지에서 찾기        |
| Ctrl + D / ⌘ + D             | 북마크 추가            |

가장 자주 쓰는 건 **닫은 탭 다시 열기**예요. 실수로 탭을 닫았을 때 정말 유용합니다.
