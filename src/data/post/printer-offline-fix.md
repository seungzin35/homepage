인쇄 버튼을 눌렀는데 아무 반응이 없고, 프린터 상태가 **"오프라인"** 으로 나올 때가 있습니다. 대부분은 아래 순서대로 하면 해결됩니다. **위에서부터 차례로** 해 보세요.

## 1. 프린터 껐다 켜기

1. 프린터 전원을 끄고 **전원 코드를 뽑습니다.**
2. **30초 정도** 기다립니다.
3. 다시 꽂고 전원을 켭니다.

단순하지만 가장 효과가 좋은 방법입니다.

## 2. 같은 와이파이에 연결돼 있는지 확인

무선 프린터라면 **프린터와 PC가 같은 와이파이**에 연결되어 있어야 합니다. 공유기를 바꿨거나 와이파이 이름이 바뀌었다면 프린터의 와이파이 설정을 다시 해야 합니다. USB 프린터라면 케이블이 제대로 꽂혀 있는지 확인하세요.

## 3. '프린터를 오프라인으로 사용' 해제하기

1. **설정** → **Bluetooth 및 장치** → **프린터 및 스캐너**로 들어갑니다.
2. 사용하는 프린터를 누르고 **인쇄 대기열 열기**를 누릅니다.
3. 대기열 창의 메뉴에서 **프린터를 오프라인으로 사용**에 체크가 되어 있다면 해제합니다.

## 4. 쌓인 인쇄 작업 지우기

인쇄 대기열에 실패한 작업이 쌓여 있으면 다음 인쇄가 막힐 수 있습니다.

- **인쇄 대기열 열기** → 오른쪽 위 **…(더 보기)** → **모두 취소**

## 5. 기본 프린터로 설정하기

1. **프린터 및 스캐너**에서 프린터를 누릅니다.
2. **기본값으로 설정**을 누릅니다.

이 버튼이 보이지 않는다면, 같은 화면 아래쪽의 **Windows에서 내 기본 프린터 관리**를 먼저 끕니다.

## 6. 인쇄 스풀러 서비스 다시 시작하기

1. `Win + R` 을 누르고 `services.msc` 를 입력합니다.
2. 목록에서 **Print Spooler** 를 찾아 마우스 오른쪽 클릭 → **다시 시작**을 누릅니다.

## 7. 프린터 제거 후 다시 추가하기

1. **프린터 및 스캐너**에서 프린터를 누르고 **제거**를 누릅니다.
2. 프린터가 켜져 있고 연결된 상태에서 **장치 추가**를 눌러 다시 추가합니다.

마지막으로 **PC를 다시 시작**해 보세요.

> 윈도우 **도움말 보기(Get Help)** 앱의 프린터 문제 해결사를 실행해 보는 것도 방법입니다. 흔한 설정 문제를 자동으로 찾아 줍니다.

## 정리

**전원 재시작 → 연결 확인 → 오프라인 사용 해제 → 대기열 비우기 → 기본 프린터 → 스풀러 재시작 → 재설치** 순서로 확인하세요. 대부분은 앞의 1~4단계에서 해결됩니다.
