아이폰 사진을 PC에 백업하고 싶은데 클라우드 용량이 부족하다면, **USB 케이블로 직접 옮기는 방법**이 가장 빠르고 무료입니다.

## 준비물

- 아이폰과 PC를 연결할 수 있는 **USB 케이블** (충전 케이블)
- 잠금이 풀린 아이폰

## 방법 1: 파일 탐색기로 직접 복사하기

1. 아이폰을 USB 케이블로 PC에 연결합니다.
2. 아이폰 화면에 **"이 컴퓨터를 신뢰하겠습니까?"** 라는 창이 뜨면 **신뢰**를 누르고 암호를 입력합니다.
3. PC에서 **파일 탐색기**(단축키 `Win + E`)를 열고 **Apple iPhone** 을 선택합니다.
4. **Internal Storage** → **DCIM** 폴더로 들어가면 날짜별 폴더 안에 사진이 들어 있습니다.
5. 원하는 사진이나 폴더를 PC의 원하는 위치로 복사합니다.

> 아이폰이 보이지 않으면 케이블을 다시 꽂고, 아이폰 잠금을 해제한 상태인지 확인하세요.

## 방법 2: 윈도우 '사진' 앱으로 한 번에 가져오기

1. 아이폰을 연결하고 **신뢰**를 누릅니다.
2. 윈도우 **사진** 앱을 열고 **가져오기** 버튼을 누른 뒤 아이폰을 선택합니다.
3. 가져올 사진을 고르고 **가져오기**를 누르면 PC의 '사진' 폴더에 저장됩니다.

사진이 많을 때는 이 방법이 더 편합니다. 이미 가져온 사진을 구분해 주기 때문입니다.

## HEIC 파일이 열리지 않을 때

아이폰은 기본적으로 사진을 **HEIC** 형식으로 저장합니다. 용량은 작지만 일부 PC 프로그램에서는 열리지 않을 수 있습니다. 이럴 때는 아이폰 설정을 바꿔 두면 됩니다.

- 아이폰 **설정** → **사진** → 맨 아래 **Mac 또는 PC로 전송** → **자동**

이렇게 설정하면 PC로 옮길 때 호환되는 형식(JPG)으로 자동 변환됩니다.

## 정리

| 상황                   | 추천 방법                       |
| ---------------------- | ------------------------------- |
| 사진 몇 장만 필요할 때 | 파일 탐색기에서 복사            |
| 전체 사진을 백업할 때  | 윈도우 사진 앱으로 가져오기     |
| HEIC 파일이 안 열릴 때 | 설정 → 사진 → '자동'으로 바꾸기 |
