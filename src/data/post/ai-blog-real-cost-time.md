"AI로 블로그 만들면 공짜 아니야?" 하고 생각하실 수 있습니다. 서버비는 0원이 맞지만, 들어간 돈이 아예 없지는 않았습니다. 이 블로그를 만들고 운영하면서 실제로 낸 돈과 쓴 시간을 그대로 적어 봅니다.

> **제 이야기**: 저는 직장인이라 따로 시간을 내기 어렵습니다. 그래서 블로그는 **쉬는 시간이 날 때마다** 휴대폰으로 조금씩 하고 있습니다.

## 1. 실제로 낸 돈

| 항목                | 금액     | 주기 |
| ------------------- | -------- | ---- |
| 도메인 (zinnote.kr) | 16,500원 | 1년  |
| ChatGPT 구독        | 29,000원 | 매달 |
| Claude Max 구독     | 100달러  | 매달 |
| 서버(호스팅)        | **0원**  | -    |

- 도메인은 한 번 내면 1년 동안 씁니다. 가비아에서 산 이야기는 [블로그 도메인 어디서 살까?](/buy-kr-domain-gabia)에 적어 두었습니다.
- 서버비는 GitHub Pages를 써서 0원입니다. 만든 과정은 [서버비 0원 홈페이지 만들기](/free-homepage-github-pages)에 있습니다.
- Claude는 달러로 결제해서, 원화로는 그달 환율에 따라 금액이 조금씩 달라집니다.

정리하면 **매달 ChatGPT 29,000원 + Claude 100달러**, 그리고 1년에 한 번 도메인 16,500원이 나갑니다. 블로그만 하려면 이렇게까지 쓸 필요는 없습니다. 무료 버전으로도 글쓰기나 간단한 수정은 충분히 도움을 받을 수 있습니다.

## 2. 쓴 시간

정해 둔 시간은 없습니다. **쉬는 시간이 날 때마다** 휴대폰으로 AI에게 부탁하고, 결과를 확인합니다.

이렇게 할 수 있는 건 AI가 코드 수정, 글 정리, 사이트 반영까지 대신 해 주기 때문입니다. 저는 무엇을 바꿀지 말하고, 사진을 찍어 보내고, 결과를 확인하는 역할을 합니다.

## 3. 그동안 한 일

숫자로 보면 이렇습니다.

- 글 **40개** (IT 팁, 블로그 운영기, 무협 게임 개발기)
- 도메인 연결, 구글 서치 콘솔과 네이버 서치어드바이저 등록
- 직접 만든 무협 게임 데모를 itch.io에 공개
- 구글 애드센스 첫 신청

## 4. 가장 힘들었던 일: 애드센스 거절

가장 힘들었던 건 **애드센스 거절**이었습니다. 이유는 "가치가 별로 없는 콘텐츠"였습니다. 받은 메일과 화면, 고치고 있는 내용은 [애드센스 첫 신청 거절 후기](/adsense-rejected-first)에 정리해 두었습니다.

거절을 계기로 블로그 방향도 다시 잡았습니다. 어디서나 볼 수 있는 팁보다, **제가 직접 해 본 도전**을 기록하는 곳으로 만들려고 합니다.

- 블로그·애드센스 도전기
- 무협 게임 개발기
- 웹소설 유료화 도전기

## 정리

- 서버비는 0원, 도메인은 1년 16,500원입니다.
- 저는 AI 구독료로 매달 ChatGPT 29,000원, Claude 100달러를 냅니다.
- 시간은 쉬는 시간이 날 때마다 조금씩 씁니다.
- 가장 힘들었던 일은 애드센스 거절이었고, 그 덕분에 방향을 다시 잡았습니다.

애드센스로 이 돈을 다시 벌 수 있을지, 앞으로도 숫자 그대로 기록하겠습니다.
