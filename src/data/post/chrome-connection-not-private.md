크롬으로 늘 가던 사이트에 들어갔는데 갑자기 화면 가득 경고가 뜨면서 **'연결이 비공개로 설정되어 있지 않습니다'** 라는 문구가 나올 때가 있습니다. 문구 아래에는 `NET::ERR_CERT_DATE_INVALID` 같은 영어 오류 코드가 함께 적혀 있습니다.

이 경고는 크롬이 사이트와 **안전한(HTTPS) 연결을 확인하지 못했다**는 뜻입니다. 원인은 내 기기 쪽일 수도, 사이트 쪽일 수도 있습니다. 구글 크롬 공식 도움말에 나온 순서대로 하나씩 확인해 보겠습니다.

<!-- 스크린샷 자리: 크롬 '연결이 비공개로 설정되어 있지 않습니다' 경고 화면 (아래 오류 코드가 보이게) -->

## 먼저 오류 코드부터 보세요

경고 화면 아래쪽 작은 글씨로 오류 코드가 적혀 있습니다. 코드에 따라 먼저 볼 곳이 다릅니다.

| 오류 코드 / 문구                                                                | 먼저 볼 곳                                         |
| ------------------------------------------------------------------------------- | -------------------------------------------------- |
| `NET::ERR_CERT_DATE_INVALID`, '시간이 너무 먼 과거로(미래로) 설정되어 있습니다' | 내 기기의 **날짜와 시간**                          |
| `NET::ERR_CERT_AUTHORITY_INVALID`, `ERR_CERT_COMMON_NAME_INVALID` 등            | 공용 와이파이 로그인, 백신 프로그램, 회사 네트워크 |
| '네트워크에 연결'                                                               | 공용 와이파이 로그인 페이지                        |

## 1. 날짜와 시간이 맞는지 확인하기 (ERR_CERT_DATE_INVALID)

구글 도움말에 따르면 **컴퓨터나 휴대기기의 날짜 및 시간이 잘못 설정되어 있으면** 이 오류가 나타날 수 있습니다. 화면에 '시간이 너무 먼 과거로 설정되어 있습니다'처럼 시계 이야기가 나오면 거의 이 경우입니다.

윈도우 11에서는 이렇게 맞춥니다.

1. **시작** 버튼을 누르고 **설정**을 엽니다.
2. **시간 & 언어** → **날짜 & 시간**으로 들어갑니다.
3. **자동으로 시간 설정**이 **켬**인지 확인합니다.
4. 같은 화면에서 **표준 시간대 자동 설정**도 켜 두거나, 표준 시간대가 **서울**로 되어 있는지 확인합니다.

<!-- 스크린샷 자리: 설정 > 시간 & 언어 > 날짜 & 시간 (자동으로 시간 설정 켬) -->

시간을 맞춘 뒤 크롬에서 페이지를 다시 열어 보세요. 휴대폰에서 같은 오류가 나면 휴대폰 설정에서도 날짜와 시간이 맞는지 확인합니다.

> 메뉴 이름은 윈도우 버전이나 업데이트에 따라 조금 다를 수 있습니다.

## 2. 카페·공항 와이파이라면 로그인 페이지 먼저 열기

카페, 공항, 호텔 같은 곳의 와이파이는 연결한 뒤 **로그인(동의) 페이지**를 거쳐야 인터넷이 됩니다. 이 로그인을 안 하면 HTTPS 사이트에서 인증서 경고가 뜰 수 있습니다.

구글 도움말에서는 `http://` 로 시작하는 주소(예: `http://example.com`)로 들어가 보라고 안내합니다. 그러면 와이파이 로그인 페이지가 열리고, 거기서 로그인하면 인터넷을 쓸 수 있습니다. 경고 화면에 **연결** 버튼이 보이면 그 버튼을 눌러도 됩니다.

와이파이는 연결됐다고 나오는데 인터넷 자체가 안 된다면 [와이파이 연결됐는데 인터넷 안 될 때](/wifi-connected-no-internet) 글도 함께 보세요.

## 3. 시크릿 창에서 열어 보기 (PC)

PC 크롬에서는 **시크릿 창**으로 같은 주소를 열어 봅니다. 오른쪽 위 **더보기(⋮) → 새 시크릿 창**을 누르거나, 단축키 **Ctrl + Shift + N** 을 누르면 됩니다.

시크릿 창에서는 열린다면 **확장 프로그램**이 원인일 수 있습니다. 구글 도움말은 확장 프로그램을 모두 사용 중지해 보고, 문제가 해결되면 하나씩 다시 켜면서 원인이 되는 것을 찾으라고 안내합니다.

## 4. 윈도우 업데이트하기

구글 도움말은 윈도우나 맥 같은 운영체제가 최신 버전인지 확인하라고 안내합니다. 오래 업데이트를 안 했다면 윈도우 업데이트를 확인해 보세요. 업데이트가 계속 실패한다면 [윈도우 업데이트 오류 해결](/windows-update-error-fix) 글을 참고하세요.

## 5. 백신 프로그램의 'HTTPS 검사' 확인하기

백신 프로그램 중에는 **'HTTPS 보호'** 또는 **'HTTPS 검사'** 기능이 있는 것이 있습니다. 구글 도움말에 따르면 이 기능이 크롬의 보안 기능을 방해해서 이 오류가 생길 수 있습니다.

- 백신을 **잠깐** 끄고 사이트가 열리는지 확인합니다.
- 확인이 끝나면 **반드시 백신을 다시 켭니다.**

## 6. 회사 컴퓨터라면 관리자에게 문의하기

회사 컴퓨터는 보안 장비(프록시)가 HTTPS 연결을 중간에서 검사하는 경우가 있습니다. 이때 필요한 인증서가 설치되어 있지 않으면 `NET::ERR_CERT_AUTHORITY_INVALID` 오류가 납니다. 구글은 **직접 인증서를 설치하지 말고** 회사 관리자에게 문의하라고 안내합니다.

## 그래도 안 되면: 사이트 문제일 수 있습니다

다른 사이트는 모두 잘 열리고 **한 사이트만** 계속 경고가 뜬다면, 그 사이트의 인증서 설정에 문제가 있을 수 있습니다. 이럴 때는 내가 고칠 수 있는 게 없으니 사이트 운영자에게 알려 주는 것이 맞습니다.

경고 화면의 **고급** 버튼을 눌러 억지로 들어가는 건 피하세요. 특히 **로그인, 결제, 개인정보 입력**이 필요한 사이트라면 경고를 무시하고 들어가지 않는 것이 안전합니다.

<!-- 스크린샷 자리: 크롬 경고 화면에서 '고급'을 눌렀을 때 펼쳐지는 설명 부분 (사이트 주소는 가림) -->

## 정리

- **ERR_CERT_DATE_INVALID / 시계 문구** → 설정 → 시간 & 언어 → 날짜 & 시간에서 **자동으로 시간 설정** 켜기
- **공용 와이파이** → `http://` 주소로 들어가 와이파이 로그인 먼저
- **PC** → 시크릿 창(Ctrl + Shift + N)으로 열어 보고, 되면 확장 프로그램 확인
- **백신의 HTTPS 검사** → 잠깐 끄고 확인한 뒤 꼭 다시 켜기
- **회사 컴퓨터** → 인증서를 직접 설치하지 말고 관리자에게 문의
- **한 사이트만 안 됨** → 사이트 쪽 문제일 수 있으니 억지로 들어가지 않기

크롬이 전반적으로 이상하게 동작한다면 [크롬 캐시와 쿠키 삭제 방법](/chrome-clear-cache-cookies)도 한 번 해 보세요.
