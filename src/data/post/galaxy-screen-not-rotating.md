동영상을 크게 보려고 휴대폰을 옆으로 눕혔는데 **화면이 세로 그대로 멈춰 있는** 경우가 있습니다. 반대로 누워서 볼 때 화면이 자꾸 돌아가서 불편할 때도 있죠.

삼성 공식 안내에 따르면 화면이 돌아가지 않는 원인은 대부분 **자동 회전이 꺼져 있거나**, **앱이 가로 화면을 지원하지 않거나**, **일시적인 소프트웨어 오류**입니다. 아래 순서대로 확인해 보세요.

> 메뉴 이름과 들어가는 경로는 기기 모델과 소프트웨어(One UI) 버전에 따라 조금씩 다를 수 있습니다.

## 방법 1: 빠른 설정창에서 자동 회전 켜기

가장 흔한 원인입니다. 화면 방향 아이콘이 **세로 모드**나 **가로 모드**로 고정되어 있으면 휴대폰을 돌려도 화면이 바뀌지 않습니다.

1. 화면 맨 위에서 아래로 쓸어내려 **빠른 설정창**을 엽니다. (두 손가락으로 쓸어내리면 전체 창이 바로 열립니다.)
2. 화면 방향 아이콘을 찾습니다. 이 아이콘에는 **자동 회전**, **세로 모드**, **가로 모드** 가운데 하나가 표시됩니다.
3. **세로 모드**나 **가로 모드**로 되어 있으면 아이콘을 눌러 **자동 회전**으로 바꿉니다.
4. 자동 회전이 켜지면 아이콘이 **파란색**으로 바뀝니다. 회색이면 고정된 상태입니다.

### 빠른 설정창에 아이콘이 없을 때

실수로 아이콘을 빼 두었을 수 있습니다. 다시 넣는 방법은 다음과 같습니다.

1. 빠른 설정창을 끝까지 내립니다.
2. **편집**(연필 모양) 버튼을 누릅니다.
3. 사용할 수 있는 버튼 목록에서 **자동 회전**(화면 방향) 아이콘을 찾아 빠른 설정창으로 끌어다 놓습니다.
4. **완료**를 누릅니다.

## 방법 2: 앱 문제인지 확인하기

자동 회전을 켰는데도 특정 앱에서만 화면이 돌아가지 않는다면, **그 앱이 원래 세로 화면만 지원**하는 경우일 수 있습니다. 삼성 안내에서도 일부 앱은 자동 회전을 켜 두어도 정해진 방향으로만 열린다고 설명합니다.

1. 다른 앱(예: 갤러리, 인터넷 브라우저)을 열고 휴대폰을 옆으로 돌려 봅니다.
2. 다른 앱에서는 잘 돌아간다면 휴대폰 고장이 아니라 그 앱의 특성입니다.

휴대폰을 돌릴 때 **손가락이 화면에 닿아 있으면** 화면이 돌아가지 않을 수 있습니다. 삼성 안내에 따르면 화면을 누른 채로 휴대폰을 돌리면 지금 방향이 유지되고, 손을 떼면 다시 자동으로 돌아갑니다. 확인할 때는 화면에서 손을 떼고 돌려 보세요.

## 방법 3: 홈 화면만 안 돌아갈 때

앱 안에서는 잘 돌아가는데 **홈 화면만 세로로 고정**되어 있다면 정상입니다. 갤럭시 홈 화면은 처음에 회전하지 않도록 설정되어 있습니다. 홈 화면도 가로로 쓰고 싶다면 다음과 같이 켭니다.

1. **설정** 앱을 엽니다.
2. **홈 화면**을 누릅니다.
3. **가로 모드로 회전**을 켭니다.

<!-- 스크린샷 자리: 설정 > 홈 화면 > '가로 모드로 회전' 스위치가 보이는 화면 -->

이 설정을 켜면 휴대폰을 옆으로 돌렸을 때 홈 화면도 함께 가로로 바뀝니다. 물론 빠른 설정창의 **자동 회전**도 켜져 있어야 합니다.

## 방법 4: 휴대폰 다시 시작하기

자동 회전이 켜져 있는데도 어떤 앱에서도 화면이 돌아가지 않는다면, 일시적인 오류일 수 있습니다.

1. 빠른 설정창을 내리고 **전원** 아이콘을 누릅니다.
2. **다시 시작**을 누르고, 한 번 더 **다시 시작**을 눌러 확인합니다.

## 방법 5: 안전 모드로 원인 앱 찾기

다시 시작해도 안 된다면, 나중에 설치한 앱이 화면 방향을 바꾸는 기능을 방해하고 있을 수 있습니다. **안전 모드**에서는 직접 설치한 앱이 잠시 멈추기 때문에 원인을 가릴 수 있습니다.

1. 빠른 설정창에서 **전원** 아이콘을 누릅니다.
2. **전원 끄기**를 길게 누르면 **안전 모드** 버튼이 나타납니다.
3. **안전 모드**를 누릅니다. 휴대폰이 다시 켜지고 화면 아래에 '안전 모드'라고 표시됩니다.
4. 안전 모드에서 휴대폰을 옆으로 돌려 봅니다.

안전 모드에서는 화면이 잘 돌아간다면, **최근에 설치한 앱**(화면 방향 조절 앱, 런처 앱 등)이 원인일 가능성이 큽니다. 휴대폰을 다시 시작해 안전 모드를 빠져나온 뒤, 최근에 설치한 앱부터 하나씩 삭제하며 확인해 보세요.

## 방법 6: 소프트웨어 업데이트하기

1. **설정** → **소프트웨어 업데이트**를 누릅니다.
2. **다운로드 및 설치**를 누르고 화면 안내를 따릅니다.

<!-- 스크린샷 자리: 설정 > 소프트웨어 업데이트 화면 (다운로드 및 설치 메뉴가 보이게) -->

와이파이가 연결된 곳에서 하면 모바일 데이터를 아낄 수 있습니다.

## 그래도 안 되면

삼성 안내에 따르면 휴대폰은 안에 있는 **가속도 센서**로 휴대폰이 어느 방향으로 놓였는지 알아내 화면을 돌립니다. 위 방법을 모두 해 봐도 계속 안 된다면 이 센서나 다른 부품 문제일 수 있으니, 데이터를 백업한 뒤 **삼성전자서비스센터**에 점검을 받아 보세요. 떨어뜨린 적이 있거나 화면에 금이 갔다면 더 빨리 맡기는 것이 좋습니다.

공장 초기화(모든 데이터 삭제)로 해결되는 경우도 있지만, 사진과 연락처 등 **모든 데이터가 지워지니** 꼭 백업한 뒤 마지막 수단으로만 생각하세요.

## 정리

| 증상                             | 먼저 확인할 곳                                  |
| -------------------------------- | ----------------------------------------------- |
| 어떤 앱에서도 화면이 안 돌아간다 | 빠른 설정창 → **세로 모드**를 **자동 회전**으로 |
| 빠른 설정창에 회전 아이콘이 없다 | 빠른 설정창 → **편집** → 아이콘 다시 추가       |
| 특정 앱에서만 안 돌아간다        | 앱이 가로 화면을 지원하는지 다른 앱과 비교      |
| 홈 화면만 안 돌아간다            | 설정 → 홈 화면 → **가로 모드로 회전**           |
| 자동 회전을 켜도 안 된다         | 다시 시작 → **안전 모드** → 소프트웨어 업데이트 |

대부분은 **방법 1**에서 해결됩니다. 화면 캡처 방법이 궁금하다면 [갤럭시 화면 캡처 방법](/galaxy-screenshot)도 함께 참고해 보세요.
