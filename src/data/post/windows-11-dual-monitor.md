노트북이나 데스크톱에 모니터를 하나 더 연결하면 작업 공간이 두 배로 넓어집니다. 그런데 막상 연결해 보면 두 화면에 같은 내용이 나오거나, 마우스를 오른쪽으로 옮겼는데 왼쪽 모니터로 넘어가는 경우가 많습니다. 윈도우 11 기본 설정만으로 해결할 수 있습니다.

> 메뉴 이름은 윈도우 버전이나 업데이트에 따라 조금 다를 수 있습니다.

## 시작하기 전에: 케이블과 업데이트 확인

1. 모니터 케이블(HDMI, DP 등)이 PC나 도킹 스테이션에 **제대로 꽂혀 있는지** 확인합니다.
2. **시작 → 설정 → Windows 업데이트**에서 업데이트를 확인해 최신 상태로 맞춥니다. 그래픽 드라이버도 함께 업데이트될 수 있습니다.

## 1단계: 두 번째 모니터 인식시키기

보통은 케이블만 연결하면 자동으로 인식됩니다. 화면이 안 나온다면 다음을 해 보세요.

1. **시작 → 설정 → 시스템 → 디스플레이**로 들어갑니다.
2. **여러 디스플레이** 항목을 펼칩니다.
3. 유선 모니터는 **검색**, 무선 디스플레이(TV 등)는 **연결**을 누릅니다.

> 무선 디스플레이 어댑터를 TV의 HDMI 단자에 꽂아 쓰는 경우에는 `Win + K` 를 눌러 바로 연결할 수도 있습니다.

## 2단계: 복제할지, 확장할지 고르기 (`Win + P`)

`Win + P` 를 누르면 화면 오른쪽에 4가지 모드가 나옵니다.

| 모드               | 이런 때 사용                                   |
| ------------------ | ---------------------------------------------- |
| **PC 화면만**      | 한 화면만 쓰고 싶을 때                         |
| **복제**           | 두 화면에 똑같은 내용 (발표, 프로젝터 연결)    |
| **확장**           | 두 화면을 이어서 하나의 넓은 화면처럼 (작업용) |
| **두 번째 화면만** | 노트북 화면은 끄고 큰 모니터만 쓸 때           |

작업 공간을 넓히는 게 목적이라면 **확장**을 고르면 됩니다. 창을 다른 모니터 쪽으로 끌어서 옮길 수 있게 됩니다.

## 3단계: 모니터 위치 맞추기

확장 모드에서 마우스가 엉뚱한 쪽으로 넘어간다면, 윈도우가 알고 있는 모니터 위치와 실제 책상 위 위치가 다르기 때문입니다.

1. **시작 → 설정 → 시스템 → 디스플레이**로 들어갑니다.
2. **식별**을 누르면 각 모니터에 **1, 2** 같은 숫자가 크게 표시됩니다.
3. 설정 화면의 모니터 그림을 **끌어서** 실제 놓인 위치대로 배치합니다. (예: 2번 모니터가 오른쪽에 있으면 그림도 오른쪽으로)
4. **적용**을 누릅니다.
5. 마우스를 두 화면 사이로 움직여 자연스럽게 넘어가는지 확인합니다.

## 4단계: 글자 크기와 해상도 맞추기

두 모니터 크기가 달라서 한쪽 글자가 너무 작거나 크다면 모니터별로 따로 맞출 수 있습니다.

1. **설정 → 시스템 → 디스플레이**에서 바꿀 모니터 그림을 먼저 선택합니다.
2. **비율 크기 조정 및 레이아웃** 부분에서 (화면에 따라 "배율 및 레이아웃"으로 보일 수 있습니다)
   - **비율 크기 조정(배율)**: 글자와 앱 크기를 바꿉니다.
   - **디스플레이 해상도**: 보통 **(권장)** 이라고 표시된 값이 가장 선명합니다.
   - **디스플레이 방향**: 모니터를 세로로 돌려 쓸 때 바꿉니다. (모니터도 실제로 돌려야 합니다)

> 해상도가 갑자기 이상하게 바뀐다면 그래픽 드라이버 업데이트가 필요할 수 있습니다. **설정 → Windows 업데이트**에서 업데이트를 확인해 보세요.

## 노트북 사용자라면: 창 위치 기억 기능

노트북을 모니터에 연결했다 뺐다 하는 경우, **설정 → 시스템 → 디스플레이 → 여러 디스플레이**에서 다음 두 옵션을 확인해 보세요.

- **모니터 연결을 기준으로 창 위치 기억**: 다시 연결하면 창이 원래 있던 모니터 자리로 돌아옵니다.
- **모니터 연결이 끊어지면 창을 최소화합니다**: 케이블을 뽑으면 외부 모니터에 있던 창이 최소화됩니다.

## 정리

| 하고 싶은 것             | 방법                                 |
| ------------------------ | ------------------------------------ |
| 모니터가 인식이 안 될 때 | 디스플레이 → 여러 디스플레이 → 검색  |
| 복제 / 확장 바꾸기       | `Win + P`                            |
| 마우스 넘어가는 방향     | 디스플레이 → 식별 → 그림 끌기 → 적용 |
| 글자 크기, 해상도        | 디스플레이 → 배율 / 해상도           |

모니터를 연결해도 화면이 아예 안 나온다면 케이블과 입력 단자부터 다시 확인해 보세요. 소리가 모니터 쪽으로 나가 버려서 PC 소리가 안 들린다면 [컴퓨터 소리가 안 날 때 해결 방법](/pc-no-sound)도 참고하세요.
