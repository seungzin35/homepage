[유료화 도전기 2화](/novel-paid-challenge-ep2)에서는 11월 7일 숫자를 공개했습니다. 그로부터 10일 뒤인 **11월 17일**, 두 작품의 숫자를 다시 확인했습니다.

> **제 이야기**: 저는 문피아에서 **이천재**라는 이름으로 현대판타지와 무협 두 작품을 연재하고 있습니다. 목표는 유료화입니다. 아래 화면은 제 작품 상세 화면을 직접 캡처한 것입니다.

## 1. 잡역부를 쫓아냈더니 종문 단약이 다 터짐 (무협)

![문피아 작품 상세 화면: 잡역부를 쫓아냈더니 종문 단약이 다 터짐, 조회수 20,599, 선호작 221, 좋아요 557](../../assets/images/posts/novel-ep3-japyeok.jpg)

|        | 11월 4일 | 11월 7일 | 11월 17일  |
| ------ | -------- | -------- | ---------- |
| 조회수 | 1,271    | 4,597    | **20,599** |
| 선호작 | 35       | 89       | **221**    |
| 좋아요 | 31       | 126      | **557**    |

**조회수가 2만을 넘었습니다.** 2화 때 4,597이었으니 10일 만에 약 **4.5배**가 됐습니다. 1화(11월 4일) 때와 비교하면 약 16배입니다. 선호작도 89에서 221로, 좋아요도 126에서 557로 늘었습니다.

## 2. 배달원은 외신의 가호를 받는다 (현대판타지)

![문피아 작품 상세 화면: 배달원은 외신의 가호를 받는다, 조회수 3,019, 선호작 34, 좋아요 285](../../assets/images/posts/novel-ep3-baedal.jpg)

|        | 11월 4일 | 11월 7일 | 11월 17일 |
| ------ | -------- | -------- | --------- |
| 조회수 | 910      | 1,314    | **3,019** |
| 선호작 | 16       | 22       | **34**    |
| 좋아요 | 117      | 153      | **285**   |

배달원도 조회수가 3천을 넘었습니다. 2화 때보다 약 **2.3배**입니다. 잡역부만큼 빠르진 않지만 꾸준히 오르고 있습니다.

## 3. 10일 동안 늘어난 숫자

| 11월 7일 → 17일 | 잡역부  | 배달원 |
| --------------- | ------- | ------ |
| 조회수          | +16,002 | +1,705 |
| 선호작          | +132    | +12    |
| 좋아요          | +431    | +132   |

- 두 작품 모두 숫자가 줄어든 곳 없이 올랐습니다.
- 잡역부는 2화 때까지만 해도 좋아요가 배달원보다 적었는데, 이번에는 557 대 285로 앞질렀습니다.
- 두 작품의 차이는 더 벌어졌습니다. 왜 이렇게 차이가 나는지는 아직 정확히 모르겠습니다.
