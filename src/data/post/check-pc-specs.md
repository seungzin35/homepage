새 게임을 설치하거나 프로그램의 **최소 사양**을 확인할 때, 혹은 중고 PC를 사고팔 때 내 컴퓨터 사양을 알아야 합니다. 따로 프로그램을 설치하지 않아도 윈도우에서 바로 확인할 수 있습니다.

> **제 이야기**: 저는 제 컴퓨터 사양을 모른 채 GTA 게임을 설치하려다 실패한 적이 있습니다. 그래서 설치 전에 사양부터 확인하는 방법을 정리했습니다.

## 방법 1: 설정에서 기본 사양 보기 (가장 쉬움)

1. 시작 버튼을 **마우스 오른쪽 클릭** → **설정**을 엽니다.
2. **시스템** → **정보**로 들어갑니다.

여기서 다음 내용을 한눈에 볼 수 있습니다.

- **프로세서:** CPU 이름 (예: Intel Core i5, AMD Ryzen 5 등)
- **설치된 RAM:** 메모리 용량
- **시스템 종류:** 64비트 / 32비트
- **Windows 사양:** 윈도우 에디션과 버전

## 방법 2: 작업 관리자로 그래픽카드까지 보기

1. `Ctrl + Shift + Esc` 를 눌러 **작업 관리자**를 엽니다.
2. 왼쪽(또는 위쪽)의 **성능** 탭을 누릅니다.
3. **CPU**, **메모리**, **디스크**, **GPU** 항목을 차례로 눌러 봅니다.

**GPU** 항목에서 그래픽카드 이름과 전용 메모리 용량을, **디스크** 항목에서 SSD인지 HDD인지도 확인할 수 있습니다. 지금 얼마나 쓰고 있는지도 실시간으로 보여 줘서 PC가 느릴 때 원인을 찾기에도 좋습니다.

## 방법 3: DirectX 진단 도구 (dxdiag)

게임 사양을 확인할 때 많이 쓰는 방법입니다.

1. `Win + R` 을 누르고 `dxdiag` 를 입력한 뒤 `Enter` 를 누릅니다.
2. **시스템** 탭에서 프로세서, 메모리, DirectX 버전을 확인합니다.
3. **디스플레이** 탭에서 그래픽카드 이름과 메모리를 확인합니다.

> 더 자세한 정보가 필요하면 `Win + R` → `msinfo32` 를 입력해 **시스템 정보** 창을 열어 보세요. 메인보드, BIOS 버전 같은 세부 정보까지 나옵니다.

## 정리

| 알고 싶은 것          | 확인 위치            |
| --------------------- | -------------------- |
| CPU, 램, 윈도우 버전  | 설정 → 시스템 → 정보 |
| 그래픽카드, SSD 여부  | 작업 관리자 → 성능   |
| 게임용 상세 사양      | `dxdiag`             |
| 메인보드 등 세부 정보 | `msinfo32`           |

_참고: Microsoft 고객지원 「Windows 디바이스에 대한 정보 찾기」_
