갤럭시 휴대폰을 오래 쓰다 보면 사진, 동영상, 앱이 쌓여서 **저장공간이 부족하다**는 알림이 뜹니다. 저장공간이 부족하면 앱을 새로 내려받거나 소프트웨어 업데이트를 하지 못할 수도 있습니다.

따로 앱을 설치하지 않아도, 휴대폰에 들어 있는 **설정**과 **갤러리**, **내 파일** 앱만으로 용량을 늘릴 수 있습니다. 아래 순서대로 하나씩 해 보세요.

> 메뉴 이름과 들어가는 경로는 기기 모델과 소프트웨어(One UI) 버전에 따라 조금씩 다를 수 있습니다.

## 먼저 남은 용량 확인하기

1. **설정** 앱을 엽니다.
2. **디바이스 케어**를 누릅니다.
3. **저장공간**을 누르면 전체 용량과 남은 용량, 그리고 이미지·동영상·오디오·문서 같은 종류별로 얼마나 쓰고 있는지 보입니다.

<!-- 스크린샷 자리: 디바이스 케어 > 저장공간 화면 -->

삼성 안내에 따르면 게임이나 앱을 내려받을 때는 **최소 1.5GB 정도**, 또는 내려받을 용량의 **2.5배 정도**의 여유 공간이 있는 것이 좋습니다.

## 방법 1: 디바이스 케어에서 필요 없는 파일 지우기

같은 **저장공간** 화면에서 바로 파일을 정리할 수 있습니다.

1. **설정** → **디바이스 케어** → **저장공간**으로 들어갑니다.
2. **이미지**, **동영상**, **오디오 파일**, **문서** 같은 항목 중 용량이 큰 것을 누릅니다.
3. 지울 파일을 고른 뒤 **삭제**를 누릅니다.

지운 파일은 바로 사라지지 않고 **휴지통**으로 옮겨집니다. 휴지통을 비워야 용량이 실제로 늘어나니 아래 방법 4까지 꼭 해 주세요.

## 방법 2: 앱 캐시 삭제하기

앱은 쓰는 동안 임시 파일(캐시)을 계속 쌓아 둡니다. 캐시는 지워도 앱의 내용이나 로그인 정보가 사라지지 않습니다.

1. **설정** → **애플리케이션**으로 들어갑니다.
2. 용량을 많이 쓰는 앱을 누릅니다.
3. **저장공간**을 누릅니다.
4. **캐시 삭제**를 누릅니다.

같은 화면에 **데이터 삭제** 버튼도 있는데, 이것은 앱을 처음 설치한 상태로 되돌립니다. **계정이나 설정 정보까지 지워질 수 있으니** 꼭 필요할 때만 누르세요.

## 방법 3: 안 쓰는 앱 삭제하기

1. **설정** → **애플리케이션**으로 들어갑니다.
2. 사용하지 않는 앱을 누릅니다.
3. **삭제**를 누르고 확인합니다.

홈 화면이나 앱스 화면에서 앱 아이콘을 길게 눌러 **삭제**를 눌러도 됩니다.

## 방법 4: 갤러리와 내 파일 휴지통 비우기

갤러리에서 사진을 지우면 **휴지통**으로 옮겨지고, **30일 동안** 보관된 뒤 자동으로 영구 삭제됩니다. 그 30일 동안은 여전히 저장공간을 차지합니다.

**갤러리 휴지통 비우기**

1. **갤러리** 앱을 엽니다.
2. 아래쪽 **메뉴**(가로줄 3개)를 누릅니다.
3. **휴지통**을 누릅니다.
4. 오른쪽 위 **더보기**(점 3개) → **비우기**를 누릅니다.

**내 파일 휴지통 비우기 (One UI 6 이상)**

1. **내 파일** 앱을 열고 **휴지통**을 누릅니다.
2. **더보기**(점 3개) → **비우기**를 누르면 휴지통의 모든 파일이 영구 삭제됩니다.

**설정** → **디바이스 케어** → **저장공간 관리** → **휴지통**에서도 같은 작업을 할 수 있습니다.

비운 휴지통은 되돌릴 수 없으니, 남겨야 할 사진이 섞여 있지 않은지 먼저 확인하세요.

## 방법 5: 사진·동영상을 옮겨 두고 지우기

용량을 가장 많이 차지하는 것은 보통 사진과 동영상입니다.

- **PC로 옮기기**: PC에 사진을 복사해 둔 뒤 휴대폰에서 지웁니다.
- **클라우드에 백업하기**: 클라우드 서비스에 백업한 뒤 휴대폰에서 지웁니다.
- **SD카드로 옮기기**: SD카드를 꽂을 수 있는 모델이라면 **내 파일** 앱에서 파일을 길게 눌러 선택하고 **이동**을 누른 뒤, **SD카드**의 원하는 폴더를 골라 옮깁니다.

옮기기 전에 백업이 제대로 되었는지 꼭 확인하고 지우세요.

## 정리

| 방법                     | 경로                                     |
| ------------------------ | ---------------------------------------- |
| 남은 용량 확인           | 설정 → 디바이스 케어 → 저장공간          |
| 앱 캐시 삭제             | 설정 → 애플리케이션 → 앱 → 저장공간      |
| 안 쓰는 앱 삭제          | 설정 → 애플리케이션 → 앱 → 삭제          |
| 휴지통 비우기            | 갤러리 → 메뉴 → 휴지통 → 더보기 → 비우기 |
| 사진·동영상 옮긴 뒤 삭제 | PC, 클라우드, SD카드에 먼저 백업         |

새 휴대폰으로 바꾸면서 카카오톡 대화도 옮겨야 한다면 [카카오톡 대화 내용, 새 휴대폰으로 옮기는 방법](/kakaotalk-backup-new-phone)도 함께 참고하세요.
