자주 가던 사이트가 갑자기 깨져 보이거나, 로그인을 해도 계속 튕기거나, 바뀐 내용이 반영되지 않을 때가 있습니다. 이럴 때 많이 하는 방법이 **크롬의 캐시와 쿠키 삭제**입니다.

- **캐시**: 사이트를 빨리 열기 위해 크롬이 저장해 둔 이미지와 파일
- **쿠키**: 사이트가 로그인 상태나 설정을 기억하려고 저장한 작은 데이터

크롬에서는 이 둘을 **인터넷 사용 기록 삭제** 메뉴에서 한꺼번에 지울 수 있습니다.

> 메뉴 이름과 위치는 크롬 버전에 따라 조금 다를 수 있습니다.

## 지우기 전에 알아 둘 점

Google 고객센터에서는 삭제하면 이렇게 된다고 안내합니다.

1. 사이트의 일부 설정이 지워집니다. **로그인해 둔 사이트는 다시 로그인**해야 합니다.
2. 이미지 등을 다시 불러와야 해서 **일부 사이트가 잠깐 느려질 수** 있습니다.

그래서 지우기 전에 자주 쓰는 사이트의 **아이디와 비밀번호를 알고 있는지** 먼저 확인해 두세요. 아이폰의 경우 Google 계정에서 로그아웃될 수 있으니 복구 전화번호와 이메일을 최신으로 해 두라고 안내하고 있습니다.

## PC(컴퓨터) 크롬에서 삭제하기

1. 컴퓨터에서 **Chrome**을 엽니다.
2. 오른쪽 위의 **점 3개(더보기)** → **인터넷 사용 기록 삭제**를 선택합니다.
3. 기간을 고릅니다. 문제가 계속된다면 **전체 기간**을 고르는 것이 좋습니다. (방금 생긴 문제라면 **지난 1시간**도 됩니다)
4. **쿠키 및 기타 사이트 데이터**를 선택합니다.
5. 캐시(이미지와 파일) 등 함께 지울 다른 항목도 선택합니다.
6. **데이터 삭제**를 누릅니다.

<!-- 스크린샷 자리: PC 크롬 인터넷 사용 기록 삭제 창 -->

> 크롬 주소창에 `인터넷 사용 기록 삭제` 라고 입력하면 나오는 버튼(작업 칩)을 눌러 바로 들어갈 수도 있습니다.

## 안드로이드(갤럭시 등) 크롬에서 삭제하기

1. 휴대폰에서 **Chrome** 앱을 엽니다.
2. 주소창 오른쪽의 **점 3개(더보기)** → **인터넷 사용 기록 삭제**를 누릅니다.
3. 기간을 고르고 **데이터 삭제**를 누릅니다. 기본 기간은 **15분**으로 되어 있으니, 오래된 문제라면 기간을 늘려 주세요.
4. 지울 항목을 직접 고르고 싶다면 **옵션 더보기**를 눌러 항목을 선택한 뒤 **데이터 삭제**를 누릅니다.

<!-- 스크린샷 자리: 안드로이드 크롬 인터넷 사용 기록 삭제 화면 -->

> 크롬에 로그인한 상태라면 쿠키를 지워도 **Google 계정에서는 로그아웃되지 않는다**고 안내되어 있습니다.

## 아이폰·아이패드 크롬에서 삭제하기

1. 아이폰에서 **Chrome** 앱을 엽니다.
2. **점 3개(더보기)** → **인터넷 사용 기록 삭제**를 누릅니다.
3. 창이 뜨면 **기간** 옆에서 기간을 고릅니다. 여기도 기본은 **15분**입니다.
4. 지울 항목을 고르려면 **인터넷 사용 기록**을 눌러 항목을 선택하고 **확인**을 누릅니다.
5. 마지막으로 **인터넷 사용 기록 삭제**를 누릅니다.

<!-- 스크린샷 자리: 아이폰 크롬 인터넷 사용 기록 삭제 팝업 -->

> 이 방법은 **크롬 앱** 기준입니다. 사파리 등 다른 브라우저는 메뉴가 다릅니다.

## 그래도 사이트가 이상하다면

- 크롬을 완전히 껐다가 다시 켜 봅니다.
- 다른 사이트는 잘 열리는데 한 사이트만 안 된다면 그 사이트 자체 문제일 수 있습니다.
- 와이파이는 연결됐는데 모든 사이트가 안 열린다면 [와이파이는 연결됐는데 인터넷이 안 될 때](/wifi-connected-no-internet)를 참고하세요.

## 정리

| 기기       | 경로                                                | 기본 기간 |
| ---------- | --------------------------------------------------- | --------- |
| PC         | 더보기 → 인터넷 사용 기록 삭제 → 기간 → 데이터 삭제 | 직접 선택 |
| 안드로이드 | 더보기 → 인터넷 사용 기록 삭제 → 데이터 삭제        | 15분      |
| 아이폰     | 더보기 → 인터넷 사용 기록 삭제 → 기간 → 삭제        | 15분      |

캐시와 쿠키를 지우면 다시 로그인해야 하는 번거로움은 있지만, 화면 깨짐이나 로그인 오류처럼 원인을 알기 어려운 문제를 꽤 많이 해결해 줍니다.
