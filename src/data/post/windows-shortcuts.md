마우스로 메뉴를 찾는 대신 단축키 몇 개만 익혀 두면 작업 속도가 눈에 띄게 빨라집니다. 윈도우 10과 11에서 모두 쓸 수 있는 단축키 위주로 골랐습니다.

> **제 이야기**: 직장에서 매일 컴퓨터를 쓰다 보니, 단축키 몇 개만 알아도 일이 확실히 편해진다는 걸 느꼈습니다. 직장인이라면 꼭 알아 두면 좋을 것들로 골랐습니다.

## 꼭 외워 둘 단축키

| 단축키               | 기능                                     |
| -------------------- | ---------------------------------------- |
| `Win + Shift + S`    | 화면 일부를 캡처 (캡처 후 바로 붙여넣기) |
| `Win + V`            | 클립보드 기록 보기 (복사한 내용 목록)    |
| `Win + E`            | 파일 탐색기 열기                         |
| `Win + D`            | 바탕화면 보기 / 다시 누르면 원래대로     |
| `Win + L`            | 화면 잠금 (자리 비울 때)                 |
| `Alt + Tab`          | 열린 창 사이 전환                        |
| `Win + 방향키`       | 창을 화면 왼쪽·오른쪽 절반으로 정렬      |
| `Ctrl + Shift + Esc` | 작업 관리자 바로 열기                    |
| `Win + .`            | 이모지·특수문자 입력                     |
| `Ctrl + Shift + T`   | (브라우저) 방금 닫은 탭 다시 열기        |

## 특히 추천하는 3가지

### 1. `Win + Shift + S` 화면 캡처

캡처할 영역을 드래그하면 바로 클립보드에 복사됩니다. 카카오톡이나 메신저 대화창에 `Ctrl + V` 로 바로 붙여 넣을 수 있어 가장 자주 쓰게 되는 단축키입니다.

### 2. `Win + V` 클립보드 기록

처음 누르면 **켜기** 버튼이 나옵니다. 한 번 켜 두면 여러 번 복사한 내용을 목록으로 보고 골라서 붙여 넣을 수 있습니다.

### 3. `Win + 방향키` 창 정렬

두 개의 창을 나란히 놓고 작업할 때 유용합니다. 한쪽 창에서 `Win + ←`, 다른 창에서 `Win + →` 를 누르면 화면이 반씩 나뉩니다.

## 정리

모두 한 번에 외우기보다, **캡처(`Win + Shift + S`)** 와 **클립보드 기록(`Win + V`)** 부터 써 보세요. 손에 익으면 나머지도 자연스럽게 따라옵니다.
