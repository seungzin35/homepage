어제까지 잘 나오던 소리가 갑자기 안 나올 때, 대부분은 **소리가 엉뚱한 장치로 출력되고 있는 경우**입니다. 아래 순서대로 확인해 보세요.

> **제 이야기**: 컴퓨터로 노래를 들으려는데 소리가 안 나와서 짜증 났던 적이 있습니다. 같은 일을 겪으셨다면 아래 순서대로 확인해 보세요.

## 1. 음소거와 볼륨 확인

당연해 보이지만 가장 흔한 원인입니다.

- 작업 표시줄 오른쪽의 **스피커 아이콘**을 눌러 음소거가 아닌지, 볼륨이 0이 아닌지 확인합니다.
- 키보드나 모니터, 스피커 자체의 볼륨과 전원도 함께 확인하세요.

## 2. 출력 장치 바로 선택하기

모니터, 이어폰, 블루투스 기기를 연결하면 소리가 그쪽으로 넘어가는 경우가 많습니다.

- 작업 표시줄 스피커 아이콘 → 볼륨 막대 옆 **화살표(>)** 를 눌러 지금 쓰는 스피커나 헤드폰을 선택합니다.
- 또는 **설정** → **시스템** → **소리** → **출력**에서 장치를 고릅니다.

## 3. 프로그램별 볼륨 확인 (볼륨 믹서)

특정 프로그램에서만 소리가 안 난다면 그 프로그램만 음소거되어 있을 수 있습니다.

- 스피커 아이콘을 **마우스 오른쪽 클릭** → **볼륨 믹서 열기**
- 해당 프로그램의 볼륨을 확인합니다.

## 4. 오디오 서비스 다시 시작하기

1. `Win + R` 을 누르고 `services.msc` 를 입력합니다.
2. 목록에서 **Windows Audio** 를 찾아 마우스 오른쪽 클릭 → **다시 시작**을 누릅니다.
3. 같은 방법으로 **Windows Audio Endpoint Builder** 와 **Remote Procedure Call (RPC)** 도 차례로 다시 시작합니다.

> 그 전에 **설정** → **시스템** → **소리** → 출력 장치 선택 → **오디오 향상**을 **끔**으로 바꿔 보는 것도 방법입니다. 일부 PC에서는 이 기능이 소리를 막기도 합니다.

## 5. 오디오 드라이버 다시 설치하기

1. 시작 버튼을 마우스 오른쪽 클릭 → **장치 관리자**를 엽니다.
2. **사운드, 비디오 및 게임 컨트롤러**를 펼칩니다.
3. 사용하는 오디오 장치를 마우스 오른쪽 클릭 → **디바이스 제거**를 누릅니다. **이 디바이스의 드라이버 제거 시도**에 체크하고 **제거**를 누릅니다.
4. PC를 **다시 시작**하면 윈도우가 드라이버를 자동으로 다시 설치합니다.

윈도우 업데이트 뒤에 소리가 사라졌다면, 같은 장치에서 **속성** → **드라이버** 탭 → **드라이버 롤백**을 눌러 이전 드라이버로 되돌려 보세요.

## 정리

대부분은 **2번(출력 장치 선택)** 에서 해결됩니다. 그래도 안 된다면 다른 이어폰이나 스피커를 꽂아 보고, 그래도 소리가 나지 않으면 하드웨어 문제일 수 있으니 서비스센터 점검을 받아 보세요.
