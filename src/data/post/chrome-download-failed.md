크롬에서 파일을 받으려고 눌렀는데 다운로드 목록에 **실패**라고 뜨고 파일이 안 받아질 때가 있습니다. 이때 실패 옆에 붙는 짧은 문구(네트워크 오류, 다운로드 차단됨, 권한 부족 등)를 보면 원인을 꽤 정확하게 알 수 있습니다.

Google Chrome 고객센터의 '파일 다운로드 오류 해결하기' 안내를 기준으로, 먼저 해 볼 것과 오류 문구별 해결법을 정리했습니다. PC(윈도우) 크롬 기준입니다.

## 먼저 오류 문구 확인하기

어떤 오류인지 모르면 해결법도 고를 수 없으니, 다운로드 목록부터 엽니다.

1. 크롬 오른쪽 위 **더보기(점 3개)**를 누릅니다.
2. **다운로드**를 누릅니다. (키보드 단축키 **Ctrl + J**로도 열 수 있습니다.)
3. 실패한 파일 아래에 적힌 문구를 확인합니다.

<!-- 스크린샷 자리: 크롬 > 더보기 > 다운로드 화면 (실패한 파일과 오류 문구가 보이게, 파일 이름이나 사이트 주소는 가림. 실패 기록이 없으면 정상 다운로드 목록 화면) -->

## 1. 대부분의 다운로드 오류에서 먼저 해 볼 것

Google은 다운로드가 안 될 때 아래 순서를 먼저 권합니다.

1. **인터넷 연결이 안정적인지** 확인합니다. 와이파이는 연결됐다고 나오는데 인터넷이 안 된다면 [와이파이는 연결됐는데 인터넷이 안 될 때](/wifi-connected-no-internet)를 먼저 보세요.
2. 연결이 돌아오면 크롬이 **자동으로 다운로드를 다시 시작**합니다.
3. 자동으로 안 되면 직접 이어 받을 수 있습니다. 주소창 오른쪽의 **다운로드 진행 중** 아이콘을 누르고, 일시중지된 파일 이름에 마우스를 올린 다음 **다시 시작**을 누릅니다.
4. 그래도 안 되면 **나중에 다시** 받아 보거나, 파일을 올린 **웹사이트 운영자에게 문의**합니다.

## 2. '네트워크 오류'가 뜰 때

인터넷 연결이 불안정하거나 중간에 끊기면 생기는 경우가 많습니다. 위 1번 순서대로 연결을 확인하고 다시 시작해 보세요.

크롬 웹 스토어에서 확장 프로그램이나 테마를 설치할 때 **'NETWORK_FAILED'**가 뜬다면 조금 다릅니다. Google은 이 경우 **원치 않는 소프트웨어**가 설치를 막고 있을 수 있다고 안내합니다.

1. 내가 설치한 기억이 없는 프로그램을 PC에서 삭제합니다.
2. 확장 프로그램이나 테마를 다시 설치해 봅니다.
3. 그래도 안 되면 크롬을 다시 설치합니다.

## 3. '다운로드 차단됨' 또는 '바이러스 검사 실패'가 뜰 때

이 문구는 **컴퓨터의 보안 설정이나 백신 프로그램이 파일을 막았다**는 뜻입니다.

- **바이러스 검사 실패, 바이러스가 발견됨**: 백신(바이러스 검사 프로그램)이 차단한 것일 수 있습니다. 왜 막혔는지는 그 백신 프로그램에서 확인합니다.
- **윈도우**: 윈도우 첨부파일 관리자가 파일을 지웠을 수도 있습니다. 어떤 파일을 받을 수 있는지는 윈도우의 인터넷 보안 설정에서 확인할 수 있습니다.

크롬 자체가 위험하다고 판단한 파일을 막는 경우도 있습니다. Google은 멀웨어(악성 프로그램), 잘 알려지지 않은 파일, 비밀번호 걸린 압축 파일처럼 검사를 피하려는 파일, 보안 연결(HTTPS)이 아닌 곳에서 받는 파일 등을 차단할 수 있다고 안내합니다.

> 크롬이나 백신이 막은 파일은 **억지로 받지 않는 것이 안전**합니다. Google도 다운로드 경고를 진지하게 받아들이라고 안내하며, 공격자가 경고를 끄거나 무시하라고 유도할 수 있다고 경고합니다. 꼭 필요한 파일이면 공식 사이트에서 다시 받으세요.

## 4. '디스크가 가득 참'이 뜰 때

PC에 파일을 저장할 공간이 부족하다는 뜻입니다.

1. 필요 없는 파일을 삭제합니다.
2. **휴지통을 비웁니다.** (지운 파일은 휴지통을 비워야 공간이 실제로 늘어납니다.)
3. 다시 다운로드합니다.

## 5. '권한 부족' 또는 '시스템 사용 중'이 뜰 때

크롬이 파일을 **PC의 저장 위치에 쓰지 못했다**는 뜻입니다. Google 안내대로 아래를 차례로 해 봅니다.

1. 다운로드를 **취소하고 다시** 받습니다.
2. 파일을 그냥 누르지 말고, 링크를 **마우스 오른쪽 버튼으로 클릭 → 다른 이름으로 링크 저장**을 고릅니다.
3. 저장 위치가 **바탕화면이나 문서 폴더처럼 내가 쓸 수 있는 폴더**인지 확인합니다.

<!-- 스크린샷 자리: 크롬에서 다운로드 링크를 마우스 오른쪽 버튼으로 클릭했을 때 메뉴 ('다른 이름으로 링크 저장'이 보이게) -->

저장 위치를 바꾸는 방법은 이렇습니다.

1. 크롬 오른쪽 위 **더보기(점 3개) → 설정**을 누릅니다.
2. 왼쪽 메뉴에서 **다운로드**를 누릅니다.
3. **위치** 옆의 **변경**을 눌러 저장할 폴더를 고릅니다.
4. 파일마다 저장 위치를 직접 고르고 싶다면 **다운로드 전에 각 파일의 저장 위치 확인**을 켭니다.

윈도우에서 위치를 바꾼 적이 없다면 기본 저장 폴더는 `\Users\(사용자 이름)\Downloads` (다운로드 폴더)입니다.

## 6. 사이트 쪽 문제일 때 ('파일 없음', '승인 필요', '금지됨')

아래 문구는 내 PC가 아니라 **파일을 올린 사이트** 쪽 문제입니다.

| 오류 문구             | 뜻                                              | 해결 방법                                                    |
| --------------------- | ----------------------------------------------- | ------------------------------------------------------------ |
| 파일 없음             | 사이트에서 파일이 없어졌거나 다른 곳으로 옮겨짐 | 사이트 운영자에게 문의하거나 다른 곳에서 파일 찾기           |
| 승인 필요             | 이 파일을 받을 권한이 없음                      | 사이트 운영자에게 문의하거나 다른 곳에서 파일 찾기           |
| 금지됨, 실패 - 금지됨 | 서버가 다운로드를 허락하지 않음                 | 그 사이트에 로그인이 필요한지 확인하고 로그인한 뒤 다시 받기 |

## 정리

| 오류 문구                           | 먼저 해 볼 것                                            |
| ----------------------------------- | -------------------------------------------------------- |
| 네트워크 오류                       | 인터넷 연결 확인 후 **다시 시작**                        |
| 다운로드 차단됨, 바이러스 검사 실패 | 백신 프로그램에서 차단 이유 확인, 억지로 받지 않기       |
| 디스크가 가득 참                    | 파일 삭제, 휴지통 비우기                                 |
| 권한 부족, 시스템 사용 중           | 다시 받기, **다른 이름으로 링크 저장**, 저장 위치 바꾸기 |
| 파일 없음, 승인 필요, 금지됨        | 사이트 로그인 확인, 운영자에게 문의                      |

크롬 버전에 따라 메뉴 이름이나 위치가 조금 다를 수 있습니다. 다운로드뿐 아니라 사이트가 아예 안 열린다면 [크롬 '연결이 비공개로 설정되어 있지 않습니다' 해결 방법](/chrome-connection-not-private)이나 [크롬 캐시와 쿠키 삭제 방법](/chrome-clear-cache-cookies)도 함께 보세요.
