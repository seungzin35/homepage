와이파이에는 연결되어 있는데 웹사이트가 열리지 않거나 **"인터넷 없음"** 이라고 표시될 때가 있습니다. 원인은 다양하지만, 아래 순서대로 확인하면 대부분 해결됩니다. **간단한 방법부터** 차례로 해 보세요.

> **제 이야기**: 어느 날 갑자기 와이파이가 안 돼서 하루 종일 답답했던 적이 있습니다. 그런 날 차근차근 확인해 볼 순서를 정리했습니다.

## 1. 다른 기기에서도 안 되는지 확인

먼저 휴대폰 등 **다른 기기로 같은 와이파이에 접속**해 보세요.

- **다른 기기도 안 된다** → 공유기나 인터넷 회선 문제입니다. 2번으로 가세요.
- **내 PC만 안 된다** → PC 설정 문제입니다. 3번부터 하세요.

## 2. 공유기와 모뎀 다시 켜기

1. 공유기(와 모뎀)의 전원을 뽑습니다.
2. **30초 정도 기다린 뒤** 다시 꽂습니다.
3. 불이 모두 정상적으로 들어올 때까지 1~2분 기다립니다.

그래도 모든 기기에서 안 된다면 인터넷 회선 문제일 수 있으니 통신사 고객센터에 문의하세요.

## 3. PC의 와이파이 다시 연결하기

- 작업 표시줄의 와이파이 아이콘을 눌러 **연결 끊기** 후 다시 연결합니다.
- 또는 **비행기 모드**를 켰다가 10초 뒤 끕니다.
- PC를 **다시 시작**하는 것도 의외로 효과가 큽니다.

## 4. 윈도우 문제 해결사 실행하기

- 윈도우 11: 시작 버튼을 누르고 **도움말 보기(Get Help)** 앱을 검색해 연 뒤, "네트워크 문제 해결"을 입력하면 자동 문제 해결사가 실행됩니다.
- 윈도우 10: **설정** → **업데이트 및 보안** → **문제 해결** → **인터넷 연결**

윈도우가 흔한 설정 문제를 자동으로 찾아 고쳐 줍니다. 그래도 안 되면 **설정** → **네트워크 및 인터넷** → **Wi-Fi** → **알려진 네트워크 관리**에서 해당 와이파이를 **삭제**한 뒤 비밀번호를 넣어 다시 연결해 보세요.

## 5. 명령어로 네트워크 설정 초기화하기

1. 시작 버튼을 누르고 `cmd` 를 검색한 뒤 **관리자 권한으로 실행**합니다.
2. 아래 명령어를 한 줄씩 입력하고 `Enter` 를 누릅니다.

```bash
netsh winsock reset
netsh int ip reset
ipconfig /release
ipconfig /renew
ipconfig /flushdns
```

3. 모두 입력한 뒤 **PC를 다시 시작**합니다.

## 6. 네트워크 초기화 (마지막 방법)

- **설정** → **네트워크 및 인터넷** → **고급 네트워크 설정** → **네트워크 초기화**

네트워크 관련 설정이 모두 처음 상태로 돌아가고 PC가 다시 시작됩니다. 저장된 와이파이 비밀번호도 지워지므로 **비밀번호를 미리 확인**해 두세요.

## 정리

**다른 기기로 원인 구분 → 공유기 재시작 → 와이파이 재연결 → 문제 해결사 → 명령어 초기화 → 네트워크 초기화** 순서로 확인하세요.

대부분은 1~3단계에서 해결됩니다.
