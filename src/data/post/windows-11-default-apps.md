링크를 눌렀는데 평소에 쓰지 않는 브라우저가 열리거나, PDF 파일을 더블클릭했는데 엉뚱한 프로그램이 뜰 때가 있습니다. 이럴 때는 윈도우의 **기본 앱** 설정을 바꾸면 됩니다.

윈도우 11에서는 두 가지 방법으로 바꿀 수 있습니다.

- **파일 형식으로 바꾸기**: ".pdf 파일은 이 프로그램으로 열기"처럼 확장자별로 정하기
- **앱으로 바꾸기**: 크롬이나 엣지 같은 앱을 골라서, 그 앱이 열 수 있는 형식을 한꺼번에 정하기

## 먼저: 기본 앱 설정 화면 열기

1. **시작** 버튼을 누르고 **설정**을 엽니다.
2. 왼쪽 메뉴에서 **앱**을 누릅니다.
3. **기본 앱**을 누릅니다.

<!-- 스크린샷 자리: 설정 > 앱 > 기본 앱 화면 -->

> 메뉴 이름은 윈도우 버전이나 업데이트에 따라 조금 다를 수 있습니다.

## 방법 1: 파일 형식으로 바꾸기 (예: PDF)

특정 확장자만 다른 프로그램으로 열고 싶을 때 쓰는 방법입니다.

1. 기본 앱 화면 위쪽의 **파일 형식 또는 링크 형식에 대한 기본값 설정** 검색창을 찾습니다.
2. 바꾸고 싶은 확장자를 입력합니다. 예: `.pdf`, `.txt`, `.jpg`
3. 아래에 나오는 결과를 누릅니다.
4. 지금 연결된 앱이 보이면 누른 뒤, 목록에서 원하는 앱을 고릅니다.

이제부터 그 형식의 파일은 고른 앱으로 열립니다.

<!-- 스크린샷 자리: .pdf 검색 후 앱 고르는 화면 -->

## 방법 2: 앱으로 바꾸기 (예: 기본 브라우저)

기본 브라우저를 바꾸고 싶을 때는 이 방법이 편합니다.

1. 기본 앱 화면에서 **응용 프로그램 기본값 설정** 목록을 봅니다.
2. 기본으로 쓰고 싶은 앱(예: 크롬, 엣지)을 누릅니다.
3. 그 앱이 열 수 있는 파일 형식과 링크 형식 목록이 나옵니다.
4. 바꾸고 싶은 형식을 누르고, 원하는 앱을 고릅니다.

브라우저 중에는 화면 맨 위에 **기본값 설정** 버튼이 따로 보이는 경우도 있습니다. 예를 들어 마이크로소프트 공식 문서에는 엣지를 고르면 **Microsoft Edge를 기본 브라우저로 설정** 옆에 **기본값 설정** 버튼이 나온다고 안내되어 있습니다. 이 버튼이 보이면 한 번에 기본 브라우저로 바꿀 수 있습니다.

<!-- 스크린샷 자리: 브라우저 선택 후 '기본값 설정' 버튼 -->

## 바꿨는데도 그대로라면

- 위 화면에서 바꾼 형식이 맞는지 다시 확인해 보세요. 기본 앱은 파일 형식(확장자)과 링크 형식(프로토콜)마다 따로 정해집니다.
- 확장자 검색 결과에 원하는 앱이 보이지 않으면, 그 앱이 해당 형식을 열 수 있는지 먼저 확인해야 합니다.

## 정리

- 기본 앱은 **설정 → 앱 → 기본 앱**에서 바꿉니다.
- 특정 파일만 바꾸려면 **확장자(.pdf 등)를 검색**합니다.
- 기본 브라우저처럼 앱 단위로 바꾸려면 **응용 프로그램 기본값 설정**에서 앱을 고릅니다.

파일이나 링크가 엉뚱한 프로그램으로 열린다 싶을 때 이 화면부터 확인해 보세요. 같은 윈도우 설정 이야기로 [윈도우 11이 느려졌을 때 꼭 확인할 설정 6가지](/windows-11-speed-up)도 함께 참고하면 좋습니다.
