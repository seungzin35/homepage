갤럭시 휴대폰에서 화면을 캡처하는 방법은 생각보다 다양합니다. 가장 기본적인 방법부터 긴 화면을 통째로 저장하는 방법까지 차례로 정리했습니다.

## 1. 버튼으로 캡처하기 (가장 기본)

**측면 버튼(전원 버튼)과 볼륨 아래 버튼을 동시에 짧게** 눌렀다 뗍니다. 화면이 한 번 번쩍이면 캡처된 것입니다.

> 너무 오래 누르면 전원 메뉴가 뜰 수 있어요. 두 버튼을 **동시에, 짧게** 누르는 것이 요령입니다.

<!-- 스크린샷 자리: 측면 버튼과 볼륨 아래 버튼 위치 -->

## 2. 손으로 밀어서 캡처하기

버튼을 누르기 어려울 때 편한 방법입니다. 먼저 기능을 켜 둬야 합니다.

1. **설정** → **유용한 기능**으로 들어갑니다.
2. **손으로 밀어서 캡처**를 켭니다. (모델에 따라 **모션 및 제스처** 메뉴 안에 있습니다.)
3. 이제 손날을 화면에 댄 채 옆으로 쓸어 넘기면 캡처됩니다.

## 3. 말로 캡처하기

음성 비서를 쓰고 있다면 말 한마디로도 캡처할 수 있습니다.

- **"하이 빅스비, 스크린샷 찍어 줘"**
- **"Hey Google, 스크린샷 찍어 줘"**

손이 젖었거나 휴대폰이 거치대에 있을 때 유용합니다.

## 4. 긴 화면 한 번에 캡처하기 (스크롤 캡처)

긴 웹페이지나 대화 내용을 한 장에 담고 싶을 때 쓰는 방법입니다.

1. 위의 방법으로 먼저 화면을 캡처합니다.
2. 화면 아래에 뜨는 도구 막대에서 **아래 방향 화살표 두 개 모양**의 **스크롤 캡처** 아이콘을 누릅니다.
3. 누를 때마다 화면이 아래로 이어서 캡처됩니다. 원하는 곳까지 왔으면 멈추면 됩니다.

## 캡처한 사진은 어디에?

- **갤러리** 앱 → **앨범** → **Screenshots(스크린샷)** 폴더
- 또는 **내 파일** 앱 → **이미지**

## 정리

| 상황               | 추천 방법                  |
| ------------------ | -------------------------- |
| 평소에 빠르게      | 측면 버튼 + 볼륨 아래 버튼 |
| 버튼 누르기 불편   | 손으로 밀어서 캡처         |
| 손을 쓸 수 없을 때 | 빅스비·구글 음성 명령      |
| 긴 화면 저장       | 캡처 후 스크롤 캡처        |

_메뉴 이름은 기종과 One UI 버전에 따라 조금 다를 수 있습니다. (참고: 삼성전자 고객지원)_
